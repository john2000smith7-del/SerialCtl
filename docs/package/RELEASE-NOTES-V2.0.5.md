# SerialCtl V2.0.5

修复 AI 过程自动折叠，远程串口只发现 SerialCtl 自身服务。

- 执行期间实时展开过程，正常完成回答后自动收起，最终回答保持可见。服务端未标注过程消息类型时，之前的 AI 中间消息也归入过程。
- 中间命令返回非零退出码不会再阻止正常完成的回合自动折叠；摘要显示“已完成 · 含失败记录”，展开可查看原始命令与输出。整个任务失败或停止时保持展开。历史恢复使用相同规则。
- 移除 UDP 识别、回退候选及连接入口；保留 SerialCtl WebSocket 7000–7015 自动发现和高级指定端口。找不到服务或串口时显示真实错误并禁用连接。
- 远程串口弹窗移除连接方式行，只保留 IP、刷新和串口下拉框，沿用现有字体、主题、圆角、间距和固定页脚。
- 沿用 V2.0.4-r1 恢复的原签名身份，交付完整 ZIP 与内嵌签名 update.json。现有原信任链客户端可跨版本自动更新，继续保留 update.ini、配置、日志与驱动；服务器先上传 ZIP，再替换 update.json。

保持原有 Win7 SP1 x64、C++17／Win32 架构以及串口、SSH、Telnet、CMD、SFTP 功能。电源连接继续处于此前的暂停开放状态。

正式发布需通过 Windows 原生构建与测试、Win7 导入检查、包重开校验、界面回归和签名校验。真实网关、实体串口及 Win7 实机未经本次受控测试验证。
