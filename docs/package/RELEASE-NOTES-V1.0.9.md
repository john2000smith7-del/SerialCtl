# SerialCtl V1.0.9

- 顶部新增 AI 入口；SSH 连接弹窗完成服务器配置、连接测试、Codex 检测和 App Server 启动。Windows 不安装 Codex，复用 Linux 用户已有模型和网关配置。
- 原终端区域显示原生对话页，AI 回复和用户消息独立成框，以蓝色强调；底部内部输入栏支持多行、模型选择、发送和停止，右侧命令/SFTP 栏保持收起。
- 支持流式回复、上下滚动、保留历史阅读位置、返回最新消息、多轮对话与服务器会话恢复；终端选中文字可附加给 AI。
- 固定高级嵌入式软件工程师角色，提供有界串口日志读取和新输出观察。关联串口必须明确选择，可填写远程 IP 查询并选择其已经开放的串口，不默认本地 COM。
- 诊断命令显示目标及完整内容，逐次确认后通过现有通道提交；不加入写入仲裁，不自动重发，不把队列提交当作设备执行成功。AI 不控制电源。
- 密码默认不保存，记住密码使用 Windows Credential Manager；通过一次性命名管道交给 Plink，校验 SSH 主机身份，凭据不写入命令行、配置或日志。
- Codex 传输和协议适配独立，网络等待在工作线程运行；AI 不可用时保留原串口、SSH/SFTP、CMD、电源与 Linux 客户端功能。

本包只经仓库既有 Windows 构建、全量自动测试、PE 子系统/导入检查、显式包清单及 ZIP 重开校验后发布。程序仍为 C++17 / Win32 x64，使用 /MT、子系统 6.01、YY-Thunks、固定 PuTTY 与 NI-VISA 18 输入。

Windows Server 2022 构建和受控测试不代表 Windows 7 SP1/10/11 现场、真实 SSH/模型网关/实体串口/电源或长时间稳定性已通过。AI 模型及工具能力仍需用实际服务器验证。历史 Linux 客户端和共享串口继续使用原协议；同一串口没有跨客户端写入仲裁。
