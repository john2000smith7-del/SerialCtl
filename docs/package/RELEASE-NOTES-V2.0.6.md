# SerialCtl V2.0.6

- 修复 SSH／AI 服务器主机密钥变化后无法更新旧身份、反复连接失败的问题。
- SSH 和 AI 连接弹窗新增“重新核验主机”入口。身份变化时显示服务器地址、端口和完整新旧指纹，核对并勾选后可更新并重新连接。
- 身份更新同时使对应的旧内存缓存失效，SSH、AI 和后续 SFTP 操作共用新指纹，无需重启软件。
- 取消核验、网络失败、指纹获取失败和身份再次变化时保留原记录。密码认证与主机身份分开处理；不自动重发 AI 或终端命令，不删除其他服务器及外部 SSH 客户端的身份记录。
- 沿用现有两文件签名更新格式、更新网址和原签名身份。

兼容性范围仍为 Windows 7 SP1／Windows 10／Windows 11 x64。构建、自动测试和导入检查不替代现场 Windows 7、真实服务器及硬件验收。
