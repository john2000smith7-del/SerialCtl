# SerialCtl V2.0.4

修复命令误触、弹窗适配、密码传递、网络握手和持续输出问题，并细化公共控件的圆角与焦点绘制。暂未完成硬件测试的电源连接功能本版先关闭。

## r1：恢复原更新签名身份

原 V2.0.0 私钥已在原工作环境中找回并通过校验。经拥有者授权，本修订恢复原验签公钥并使用原私钥签署更新，保留下述 V2.0.4 新增功能。原 V2.0.2 客户端可直接自动升级到本修订，无需先安装 V2.0.3；先上传 ZIP，再替换配套 update.json，更新网址不变。

产品版本仍为 V2.0.4。曾手动安装使用新公钥的原 V2.0.4 的电脑不能通过原身份清单完成同版本更新，需另行迁移或手动部署。新钥匙加密备份保留为历史记录，不覆盖原私钥；本次未生成新签名身份。

- 电源页点击“连接”显示“该功能暂未开放，请等待后续开放。”的小弹窗，使用公共圆角按钮和深浅主题。生产服务同时拒绝建立连接，不枚举或打开电源设备。
- AI 连接成功后在空白对话中自动介绍高级嵌入式软件工程师助手的能力；不公开内部姓名，不重复插入已有对话，不自动提交任务，不介绍暂未开放的电源控制能力。
- 命令按钮内松开才提交，拖出取消；系统双击间隔内的同一命令合并一次，停止宏仍立即生效。AI 忙碌时发送不再变成停止，停止位于独立按钮。
- 十步宏弹窗可滚动，确定/取消固定可见，键盘焦点自动进入视口。所有文本框支持 Ctrl+A，Ctrl+F6 / Ctrl+Shift+F6 切换窗格。
- 后台连接状态及宏结束原因随会话恢复，未读错误在连接列表提示。面板及名称列宽度按 96 DPI 逻辑尺寸保存；旧配置有 SavedDpi 时据此迁移，否则按首次启动的当前 DPI 解释。
- 持续输出时缩放窗口，先按最终客户区尺寸提交控件布局，再处理终端重排，避免主题和侧栏按钮短暂停留在旧位置。
- 主窗口显示前先提交初始控件布局，避免首次快速点击仍命中按钮的临时创建位置。
- 普通 SSH、SFTP、AI 与主机验证均用当前用户 ACL 限制的一次性本机命名管道传递密码，命令行仅包含管道名。
- WebSocket 握手总期限 1500ms。SSH 验证输出上限 256 KiB，SFTP 子进程输出上限 32 MiB，目录条目上限 16384；超限明确报错，不返回伪完整目录；每轮读取有预算并检查取消。
- 公共按钮、输入框和焦点线统一按实际 DPI 计算像素覆盖面积，圆弧每像素使用 32 个垂直亚像素采样和连续水平覆盖；消除旧蒙版单点缩小和独立焦点路径的台阶，文字及直线不做模糊。AI 历史按钮圆角一致；深色强调文字和禁用状态统一。结果按尺寸、DPI、配色缓存，平坦区域批量填充，单次 AlphaBlend 呈现。
- 双文件更新继续使用完整包，支持跨版本升级，不依赖旧 ZIP、中间版本或旧 VERSION/说明文件；补充缺失旧运行文件时的下载、替换与回滚回归检查。
- 保留原 V2.0.4 替换身份的加密仓库备份和校验恢复工具；原身份的活动记录与历史备份分开，恢复口令、明文私钥和恢复包不进入应用发布包或更新服务器。

保留现有可信内网使用方式及无认证网络服务。补丁升级提高真实产品版本，沿用现有双文件签名更新机制与配置。

正式交付前必须完成 MSVC x64、Windows 7 导入检查、单元/集成测试以及原生 Windows 界面验证；交叉构建和 Wine 结果只作补充证据。
