# SerialCtl V1.0.1 发布说明

本版本修复代码审核发现的终端、SSH、中文解码和共享串口问题，保持 Windows 7 SP1 为最低目标。

## 改进

- 拒绝终端负数参数，限制超大参数与重复指令工作量，修复异常输出引发的堆越界写入。
- 首次 SSH 连接显示主机指纹，由操作者核对并确认；确认后的指纹保存到当前用户注册表，变化时拒绝连接。已有 PuTTY 主机密钥缓存继续校验。
- 连接建立移到工作线程，网络连接采用可取消、有超时的等待，减少连接期间界面无响应。
- 修复 GBK/GB2312 完整汉字和分片数据的边界识别。
- 共享串口保留握手之后的数据；每客户端使用有界发送队列，慢客户端不会阻塞串口读取。最多 32 个同时连接的共享客户端。
- 退出时回收连接工作线程和待处理消息；共享客户端线程及时回收。
- 补充输入、主机信任与持久保存、握手合包和慢客户端回归测试，建立 GitHub Windows 自动构建流程。
- 固定受哈希控制依赖的 checkout 字节，补齐发布与硬件验收文档。

SFTP 现有覆盖确认继续保留；早期审核中的“未经确认覆盖”结论经完整调用链复核后已更正。

## 获取和运行

在 GitHub Releases 下载 `SerialCtl-V1.0.1-Win7.zip` 并完整解压。
32 位 Windows 7 使用 `windows/x86/native/serialctl.exe`；64 位 Windows 7 可使用 `windows/x64/native/serialctl.exe`。
serialctl.exe、plink.exe、psftp.exe 必须保持在同一架构目录。

## 验证范围

正式构建使用 MSVC 静态 /MT、YY-Thunks 和 PE 子系统 6.01。
GitHub 构建包含两种架构的自动测试、依赖/PE/API/版本校验及压缩包解压后哈希核对。
Windows Server 上启动成功不能证明全部 Win7 驱动和现场行为正常。真实 Windows 7 SP1、USB 串口、现场 SSH/SFTP 与长时间运行验收未运行，步骤随包提供。

SSH 密码仍通过 PuTTY 命令行传递；多用户环境优先使用 Pageant/密钥。共享串口仍仅适合可信内网，无认证或加密。
