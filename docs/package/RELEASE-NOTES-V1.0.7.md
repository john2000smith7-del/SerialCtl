# SerialCtl V1.0.7

新增内网自动更新。编辑 `serialctl.exe` 旁的 `update.ini`，填入完整清单网址即可在每次启动时后台检查；后续服务器地址变化只需修改该文件。默认网址留空，因为 `172.16.2.188` 的实际发布路径尚未确定。

- 下载清单和文件后，使用内置 RSA-2048 公钥验证签名，再核对文件长度、SHA-256、版本和固定文件白名单。HTTP 也不能绕过签名校验。
- 只在没有会话、连接建立、SFTP/命令/电源任务等活动时安装；更新工作进程等待主程序退出，备份后替换，遇到可处理失败恢复旧文件。
- 更新只替换白名单程序和说明文件，保留 `update.ini`、用户配置、命令、日志及 NI-VISA 驱动。
- 保持 Win7 SP1 x64、C++17/Win32、`/MT`、PE 子系统 6.01、YY-Thunks 与固定 PuTTY；不增加客户端 Python、.NET、VC Runtime 要求。
- 增加管理员离线签名工具、静态 HTTP 目录部署说明，以及断网、错误签名、文件占用和更新恢复测试清单。

首次部署本版本仍需解压正常发布包，V1.0.6 及以前没有更新器。程序目录应对当前用户可写；不会自动提权。服务器地址未配置时不连接任何假定的更新目录。

本版本以更新功能为新增范围，不代表之前独立审核登记的所有问题已修复。真实 Win7、实体串口/IT6332A、真实服务器部署和长时间运行结果需查看当前提交对应的验收记录，不能用 Windows Server 2022 CI 替代。
