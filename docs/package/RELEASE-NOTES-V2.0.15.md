# SerialCtl V2.0.15

- 修复共享下拉框强制改变原生弹出方向/高度导致打开点击触发跳底的风险，保留原生鼠标捕获与选中流程；动态列表打开期间不重建，确认选择后再查询目录或切换终端。
- 工作空间按当前目录逐级浏览，只列子目录；上一级返回父目录。完整路径单击展开、底部横向滚动，双击编辑、Ctrl+C复制，提交始终使用完整路径；连接弹窗和新建会话保持一致。
- 左侧连接栏可收起为48逻辑像素窄栏，复用小型标题图标及展开箭头，保留200ms过渡、固定按钮位置和状态记忆；收起不关闭连接，终端/AI使用释放的空间。
- 内置U-Boot连续空格、飞腾UEFI连续F2两套策略。登录板端Shell后，只提交一次重启命令，立即发送首个按键，之后按300ms（可500ms）间隔在本地连续发送按键，不等待启动关键词或模型往返；按板卡连接记忆预设。不设发送次数上限，默认持续到实际提示符/菜单或停止/断线；可显式设置超时。
- 保留legacy boot_arm及现有串口、SSH、CMD、SFTP和Python/WebSocket方式；本次不开放禁用的电源硬件控制。
- 沿用原签名身份、既有update.ini及ZIP/update.json双文件更新。正式交付需通过精确发布包签名和旧版本升级验证。

验证范围以对应Windows构建和升级记录为准。受控串口/UEFI输出、Windows CI及Win7导入检查不代表飞腾/海思真机、真实Windows 7或现场网关验收。
