# SerialCtl V1.0.3

仅提供 Windows 7 SP1 x64、Windows 10/11 x64 的便携包。

- 新增 IT6332A 电源页面，USB/VISA、RS232 和明确标识的模拟连接；批量勾选通道加电/掉电、电压电流设置与回读、监测、定时循环、停止和正常退出关闭任务通道、日志。
- 新增本地 CMD，保留会话状态；GUI 与 AI 使用同一个进程输入和输出。
- 新增按资源及操作授权的 HTTP API、WebSocket 和 Linux 客户端。API 默认关闭，密钥可通过关闭或更新撤销；保留旧串口 TCP，提供独立关闭选项。
- 修复弹窗确认后的前后台顺序、SFTP 列宽触发整窗布局、终端缩放空白历史、损坏/空命令文件、导入未保存草稿、控制键重复、模态文件操作快照、日志错误、收发缓冲、断线状态、密码空格、字体和侧栏布局。
- 发布包包含完整 NI-VISA 18.0 Runtime 离线安装文件及许可证；应用主目录直接运行。

真实 Win7、IT6332A USB/RS232 硬件和现场 SFTP 尚未验收。模拟测试仅证明应用流程，不能证明实际设备兼容性。USB 断开、程序崩溃或供电中断时不能保证电源输出关闭。任务采用软件定时，非精确同步触发。CMD 的 Win7 管道模式适合普通命令和脚本，不支持完整控制台交互或可靠 Ctrl+C。
