# SerialCtl V2.0.10

- 优化命令卡片拖动：卡片正文可拖动，移动到系统阈值后显示随鼠标移动的圆角预览和插入位置。
- 减少列表重绘和拖动闪烁，放慢边缘自动滚动；支持 Escape 和列表外松手取消，运行及编辑按钮保持独立。
- 优化本地串口重叠读写、接收绘制、远程发现和连接回收；配置后台保存，拖动窗口及侧栏时延后终端重排，减少交互阻塞。
- 分离终端视口、命令宏、AI 设备策略和 SFTP 控制器，保留原有界面与升级行为。
- 按本次交付要求禁用电源功能：不枚举或打开 USB/VISA、RS232 电源，GUI 仅显示未开放提示，AI 与远程接口无法提交电源操作。
- 保持现有双文件自动更新方式和原签名身份。

Windows 自动测试、受控鼠标操作与实际 Windows 7 及现场设备验收分别记录。
