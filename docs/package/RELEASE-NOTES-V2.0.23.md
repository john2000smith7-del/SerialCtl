# SerialCtl V2.0.23

- AI 通过已选定的 SSH 连接和远程 Python 3 比对任务前后的工作目录，记录新增、修改和删除。远程 Codex 上报的补丁也会保留。
- TFTP 停止时取消协议等待并回收传输线程，保留传输状态，同一端口可以重新启动。
- RS232 电源显式设置串口错误处理，只有设备回读 0 或 1 时确认输出状态。
- 可切换鲸鱼娘（15 个动作）、水豚噜噜（12 个动作）和小猫（12 个动作）。三套角色会跟随 AI 状态，在停放位置附近的小圆形范围内漫游。
- 寄存器卡片同时显示十六进制、无符号十进制和 32 位位图。沿用原有十六进制触发规则，普通数字选区也按十六进制解释。
- 命令笔记识别空白分隔的行尾备注标记 `#`、`//` 和 `/#`，保留双引号、单引号内的文字及 URL、路径和命令参数。
- MCP 可打开 TFTP、切换到 AI 实时终端及执行输出和修改面板。连接请求继续使用现有连接卡片和设备授权流程。

正式构建、签名和升级验证状态以对应 GitHub Actions 记录为准。
