# SerialCtl V2.0.1

- 顶部导航长条结束于“设置”之后，深浅主题按钮独立位于右上角。主题按钮圆角外部使用窗口底色，补足原生按钮触发后的完整重绘。
- 顶部导航与主卡片、左中右卡片之间的间距统一为 12 个逻辑像素，按系统 DPI 缩放。
- update.ini 默认地址：http://172.16.3.188/external/serial/update.json。两个更新文件放在同一网站目录，先上传 ZIP，再替换 JSON；ZIP 不解压、不改名。已有安装的 INI 不会被在线更新覆盖，旧地址或空白需手动修改一次。
- 沿用 V2.0.0 签名身份，交付完整 ZIP 和内嵌签名 update.json。V2.0.0 可自动升级；更早的旧协议客户端需手动安装一次 V2 系列。
- Windows 构建和替身回归不代表已完成真实 Win7/10/11、内网站点和实体设备验收。
