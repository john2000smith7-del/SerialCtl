# SerialCtl V2.0.7

本版改进命令拖动/文件导入、默认折叠的 AI 过程、真实按键与屏幕读取、服务器工作空间选择，并开放电源连接与双栏实时终端。

- 命令卡片跟随鼠标、边缘滚动；TXT 拖入只导入不执行；添加按钮按实际宽度切换。
- 电源/实时终端默认五五开、独立调宽；通道卡片窄宽纵排，固定底部操作。真实 USB/VISA、RS232 需安装对应驱动并现场测试。
- AI 过程从开始折叠，失败信息保留；交互 TUI 文本、真实 Enter 和屏幕读取分离；修复 CSI u 与 Shift 滚轮兼容。
- 本地 U-Boot 监听与有限打断；自动恢复只对用户明确绑定的板卡通道，OFF读回后至少等待10秒，停止/断线取消待上电。静默不等于卡死，烧录等不可机械恢复。
- 默认新用户名 linux；目录下拉显示真实服务器目录；新会话选择工作空间，历史恢复自己的目录。jiojio 仅被问及姓名时自报名字。
- 使用原签名身份，发布包和内嵌签名 update.json 仍为仅有两个部署文件。现有 update.ini、配置和用户数据保留。

受控协议、模拟电源和 Windows CI 验证不代表物理 Win7、真实电源、用户服务器 Codex/Hermes 现场验收通过。
