# SerialCtl V2.0.0

- 在线更新支持完整发布 ZIP 与内嵌 RSA-2048/SHA-256 签名的 update.json 两文件。
- 保留启动自动检查、原 update.ini URL 配置和空闲安装重启；只替换明确允许的运行文件，保留配置、命令、日志和驱动，保留失败恢复机制。
- 完整 ZIP 通过流式下载和签名摘要验证，有限解压白名单文件；不调用 PowerShell、Shell 解压或外部运行库，维持 Win7 SP1 x64、C++17/Win32、/MT、6.01 和 YY-Thunks。
- 保留串口、AI、SSH/SFTP、CMD、电源及 Linux 客户端功能。首次切换需要手动部署此版本。
- 经用户授权启用新的更新签名公钥，后续正式更新沿用该签名身份；私钥不随包、不上传更新站点。旧版本首次需手动安装 V2.0.0。

正式交付前需完整 Windows 构建、全量测试、PE/导入检查和 ZIP 重开验证；构建与离线替身不能代替真实 Win7、内网服务器、实体设备、断电或长时间验收。
