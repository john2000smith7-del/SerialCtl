# SerialCtl V1.0.5

电源页按审核效果图重新布局，保留左连接栏和右侧折叠栏。常用设置、统一加电/掉电放在最前面，监测、自动化、设备设置、日志与诊断分组展示。

- CH1＋CH2 串联、并联、1:1 跟踪，切换前掉电并解除旧关系，回读确认后保持掉电。
- 独立通道可使用不同电压/限流；组合卡使用总电压或总电流，均分到两路物理通道并检查回读。
- 实测趋势、采样设置、暂停显示和完整分卷 CSV/日志导出。
- 循环、定时、步骤序列；设备输出定时器与触发设置；任务文件保存/载入。
- 设备电压上限、硬件 OVP、独立软件阈值；1–36 号设备预设和本地方案；屏幕、控制方式、蜂鸣和本机 SCPI 诊断。
- 顶部去掉外框，串口采用桌面图标的黑白终端/线缆造型，远程串口增加双向箭头。桌面图标不变。
- 侧栏 200ms 缓动，动画期间继续收发，结束时统一更新终端网格。

AI 接口范围保持连接/状态查询及勾选通道总加电/掉电，不开放配置、模式、保护、任务、预设、面板和诊断写入。

仅 x64；Windows 7 SP1 最低系统版本、子系统 6.01、静态运行库和 YY-Thunks 保留。发布 ZIP 根目录直接包含 EXE、必要工具及说明，USB 驱动位于 drivers/ni-visa18。

验证范围为 GitHub Windows 构建、自动化服务测试、真实 EXE 深浅主题截图、PE 与压缩包检查。尚未进行真实 Win7 SP1、IT6332A、USB/RS232 接线及长时间硬件验收。组合模式需要按厂商说明手动接线，软件不替代接线。
