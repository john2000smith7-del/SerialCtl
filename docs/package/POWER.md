# IT6332A 电源管理

点击顶部“电源”进入控制页面。串口、SSH、CMD 等已有会话继续收发，右侧保留折叠栏。连接弹窗提供 USB 和 RS232 两种方式；USB 驱动未安装时，可运行发布包 drivers/ni-visa18/setup.exe，安装后按提示重启。RS232 默认 9600/8/N/1，必须与电源面板一致，并独占 COM。连接通过 *IDN? 识别 IT6332A，只读状态，不复位或自动加电。

常用操作

- 勾选通道卡，再使用统一“应用设置”“加电”“掉电”。取消勾选不改变输出。独立模式下每个通道可以设不同电压和限流；整个参数批次先检查范围，再写入及回读。CH1/CH2 额定 30 V、6 A，CH3 5 V、3 A。
- 工作模式提供独立、CH1＋CH2 并联、CH1＋CH2 串联、1:1 跟踪。切换模式前确认手动接线正确；软件关闭三路输出、解除旧组合、应用新模式并回读，完成后仍掉电。连接不会替你解除原有组合。
- 串/并联显示一个 CH1＋CH2 组合卡，CH3 独立。串联输入总电压（最大 60 V），两路均分；并联输入总电流限值（最大 12 A），两路均分。测量按物理通道回读聚合。跟踪两路按 1:1 使用 CH1 参数；CH2 参数字段只读，不提供手册未定义的任意比例命令。
- 组合的 CH1/CH2 必须同时操作；若任何一路保护触发，关闭整个相关组合。正常单通道和任务不操作未选通道。模式切换、复位、预设恢复、自检和 SCPI 调试是整机维护操作，会明确确认或注明关闭三路输出。

监测与自动化

监测页显示实际测量趋势，默认约 1 秒，也可选择 2 秒。通信耗时会延长间隔，三通道采样并非严格同步；暂停显示不会停止设备监测或日志。

循环按加电/掉电时长和次数运行。定时任务使用本机日期时间 YYYY-MM-DD HH:MM:SS，一次开始/掉电；不后台开机或恢复任务。步骤序列在“编辑步骤”中按行填写电压、限流、保持秒数、输出 1/0，可保存/载入 JSON 任务。保持最短 0.1 秒，不承诺毫秒级硬实时切换。停止、完成、正常退出时尝试关闭任务持有的通道；手动掉电取消未来加电，保留任务输出的退出清理责任。拔线或关闭进程后不能保证设备已掉电，程序将状态标为未知。重连不恢复任务。

设备定时器使用 OUTP:TIM 和 OUTP:TIM:DEL（0.1–99999.9 秒），属于设备整机功能，不是软件任务计时；配置不自动加电。触发页设置延时、电压/电流步进，并使用已选通道卡内的电压和限流作为触发值，通过 *TRG 执行；也可用升步/降步按钮按设备步进值调整电压或电流并回读。触发写入前必须处于独立模式。

设备设置与诊断

输出与保护提供电压设置上限、硬件 OVP 开关/阈值、软件电压/电流阈值。先点击“读取”，再设置和应用；软件阈值 0 表示关闭该项，CH3 硬件 OVP 可达 5.5 V。软件检测依赖采样和通信，不能替代设备硬件限流、OVP/OTP。清除保护前应排查原因，软件关闭相关输出后才请求清除。重新连接不沿用软件阈值。

设备预设支持 1–36 号存储位置；恢复前关闭三路输出，并确认恢复后的状态。文件方案保存当前通道参数，载入要求已连接且模式相符。面板与控制提供本地/远程、LOCAL 键锁定、屏幕显示、ASCII 屏幕文字和单次蜂鸣。设备不存在锁状态查询，不把最后一次设置当作硬件回读。

日志与诊断提供设备身份、错误队列（读取会消费队列）、状态寄存器、自检、本机单条 SCPI 和设备复位。维护操作应在任务停止后执行，SCPI 调试前后保持三路输出掉电。

日志位于 %LOCALAPPDATA%\SerialCtl\logs，操作记录与 CSV 自动生成；导出合并全部日志分卷。单卷约 64 MiB，CSV 表头在首卷。磁盘写入失败/队列满会显示错误，不能继续宣称日志完整。页面最近记录有数量上限，完整记录在导出日志中。

AI 接口保留状态查询与页面勾选通道的总加电/掉电，组合卡作为整体；模式、参数、保护、任务、预设、面板及诊断仅本机操作。
