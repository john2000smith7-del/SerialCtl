# IT6332A 电源管理

**V2.0.7：开放 USB/VISA 与 RS232 电源连接。** 使用真实设备前核对接线、通道、电压和限流。电源页默认与实时终端等分，终端下拉只选择已经打开的连接，拖动中间间隔调宽；正文可滚动，操作按钮固定在底部。

点击顶部“电源”进入控制页面。串口、SSH、CMD 等已有会话继续收发，右侧保留折叠栏。连接弹窗提供 USB 和 RS232 两种方式；USB 驱动未安装时，可运行发布包 drivers/ni-visa18/setup.exe，安装后按提示重启。RS232 默认 9600/8/N/1，必须与电源面板一致，并独占 COM。连接通过 *IDN? 识别 IT6332A，只读状态，不复位或自动加电。

常用操作

- 勾选通道卡，再使用统一“应用设置”“加电”“掉电”。取消勾选不改变输出。独立模式下每个通道可以设不同电压和限流；整个参数批次先检查范围，再写入及回读。CH1/CH2 额定 30 V、6 A，CH3 5 V、3 A。
- 工作模式提供独立、CH1＋CH2 并联、CH1＋CH2 串联、1:1 跟踪。切换模式前确认手动接线正确；软件关闭三路输出、解除旧组合、应用新模式并回读，完成后仍掉电。连接不会替你解除原有组合。
- 串/并联显示一个 CH1＋CH2 组合卡，CH3 独立。串联输入总电压（最大 60 V），两路均分；并联输入总电流限值（最大 12 A），两路均分。测量按物理通道回读聚合。跟踪两路按 1:1 使用 CH1 参数；CH2 参数字段只读，不提供手册未定义的任意比例命令。
- 组合的 CH1/CH2 必须同时操作；若任何一路保护触发，关闭整个相关组合。正常单通道和任务不操作未选通道。模式切换、复位、预设恢复、自检和 SCPI 调试是整机维护操作，会明确确认或注明关闭三路输出。

监测与自动化

监测页显示实际测量趋势，默认约 1 秒，也可选择 2 秒。通信耗时会延长间隔，三通道采样并非严格同步；暂停显示不会停止设备监测或日志。

循环按加电/掉电时长和次数运行。定时任务使用本机日期时间 YYYY-MM-DD HH:MM:SS，一次开始/掉电；不后台开机或恢复任务。步骤序列在“编辑步骤”中按行填写电压、限流、保持秒数、输出 1/0，可保存/载入 JSON 任务。保持最短 0.1 秒，不承诺毫秒级硬实时切换。停止、完成、正常退出时尝试关闭任务持有的通道；手动掉电取消未来加电，保留任务输出的退出清理责任。任务运行时拒绝本机或 AI 手动加电，先停止任务再进行手动控制。拔线或关闭进程后不能保证设备已掉电，程序将状态标为未知。重连不恢复任务。

「自动化 → 关键字测试」使用本机 USB 或 RS232 电源，默认监听右侧选中的已连接终端。运行期间绑定同一条终端连接。点「关键字配置」添加多条规则，可独立填写上电完成标志、每条规则的检测开始与结束标志，以及捕获或未捕获时发送的单行指令和延迟。

每轮在上电前开始监听，按终端编码匹配新接收的文本，支持关键字跨数据块。每次命中都计数，填了指令就按顺序发送一次。指令留空时只计数。未填写检测标志时使用本轮的检测起止时间。检测窗口打开且结束时零次命中，才执行未捕获动作。若结束标志未出现，本轮检测结束时关闭窗口。若上电完成标志未出现，记录本轮超时。

检测结束后等本轮动作完成传输写入再掉电，动作延迟可能延长本轮实际供电时间。动作提交后等待写入超过 30 秒会停止测试。统计表显示本轮、累计和已写入次数，逐次记录可通过「日志与诊断 → 导出日志」查看。写入成功表示已交给终端传输，设备执行结果以设备回显为准。停止测试或终端断开会取消未写出的指令，重新连接后手动启动新测试。

设备定时器使用 OUTP:TIM 和 OUTP:TIM:DEL（0.1–99999.9 秒），属于设备整机功能，不是软件任务计时；配置不自动加电。触发页设置延时、电压/电流步进，并使用已选通道卡内的电压和限流作为触发值，通过 *TRG 执行；也可用升步/降步按钮按设备步进值调整电压或电流并回读。触发写入前必须处于独立模式。

设备设置与诊断

输出与保护提供电压设置上限、硬件 OVP 开关/阈值、软件电压/电流阈值。先点击“读取”，再设置和应用；软件阈值 0 表示关闭该项，CH3 硬件 OVP 可达 5.5 V。软件检测依赖采样和通信，不能替代设备硬件限流、OVP/OTP。清除保护前应排查原因，软件关闭相关输出后才请求清除。重新连接不沿用软件阈值。

设备预设支持 1–36 号存储位置；恢复前关闭三路输出，并确认恢复后的状态。文件方案保存当前通道参数，载入要求已连接且模式相符。面板与控制提供本地/远程、LOCAL 键锁定、屏幕显示、ASCII 屏幕文字和单次蜂鸣。设备不存在锁状态查询，不把最后一次设置当作硬件回读。

日志与诊断提供设备身份、错误队列（读取会消费队列）、状态寄存器、自检、本机单条 SCPI 和设备复位。维护操作应在任务停止后执行，SCPI 调试前后保持三路输出掉电。

日志位于 %LOCALAPPDATA%\SerialCtl\logs，操作记录与 CSV 自动生成；导出合并全部日志分卷。单卷约 64 MiB，CSV 表头在首卷。磁盘写入失败/队列满会显示错误，不能继续宣称日志完整。页面最近记录有数量上限，完整记录在导出日志中。

AI 接口保留状态查询与页面勾选通道的总加电/掉电，组合卡作为整体；模式、参数、保护、任务、预设、面板及诊断仅本机操作。

指令依据 ITECH IT6300 Programming Guide（包含 IT6332A）：[厂商英文版](https://usa.itechate.com/uploadfiles/%E7%94%A8%E6%88%B7%E6%89%8B%E5%86%8C/user%20manual/it6300/IT6300%20Programming%20Guide-EN.pdf)，[厂商中文编程手册镜像](https://www.jdingtech.com.tw/Official/sharefile/ITECH_Protocol_IT6300_V1.0.0.1.pdf)。当前没有实机，具体固件、接线、设备定时器作用范围与 Win7 驱动仍需人工确认；开发验收清单保留在源码仓库 docs/testing/WIN7-HARDWARE-TEST.md，软件包不附带开发测试资料。历史验收记录不等于当前设备已验证。

## AI 绑定恢复

先在右侧选择板卡的本地/远程串口，再勾选供电通道，勾选底部“允许 AI 恢复关联串口”。该授权只绑定当前板卡、当前真实电源身份/模式和通道；更换目标/通道/模式、断线后重新启用。普通 SSH 服务器不能绑定恢复。

AI 先读屏幕/实际日志判断是否等待输入或正常长耗时，3–5秒无输出不直接断电。恢复任务确认关闭输出后至少等10秒再开启并读回，停止任务/断线取消尚未发生的开启；每轮最多一次，不循环重启。开启失败或读回未知时如实报告，不自动重试。U-Boot 使用实际板卡提示预先装好本地捕获，收到新提示符才确认进入。

## 开发分支 V2.0.20：RS232/SCPI 连接诊断

RS232 参数须与设备面板一致。如设备显示 `4800, 8, N, 1, Single`，SerialCtl 连接窗口应设 4800/8/N/1；Single 是单机通信方式，不必改为多机模式。另须检查电源的 SCPI Command 模式是否为 ITECH。

连接顺序为打开串口/VISA → `*IDN?` 确认 IT6332A → `SYST:REM` 请求远程控制 → `INST:NSEL 1` 和读回 → 工作模式查询 → 首次轮询。不会自动 `*RST` 或输出 ON。

### 远程控制已连接的电源

1. 在电源所在电脑的 `settings.ini` 中，将控制端的 IPv4 地址加入现有 `[SerialShare]` 下的 `AllowedClients`（多个地址用逗号分隔）。重启后在该电脑本地解锁 Test，并使用 USB 或 RS232 连接电源。
2. 在控制端本地解锁 Test，打开「连接电源」，选择「远程」。填写电源所在电脑的 IPv4 地址，点击刷新，确认找到的设备后点击连接。两端需运行支持此功能的 SerialCtl。
3. 两端可同时查看状态和提交操作，由电源所在电脑依次执行并读回。远程支持通道设置、加电、掉电、工作模式和任务等操作。原始 SCPI、自检、复位、AI 恢复和日志导出在电源所在电脑操作。

刷新与连接只读取状态。控制端断开或网络丢失时，电源所在电脑保留物理连接和当前输出，取消该控制端尚未开始的命令。已开始执行的操作和已启动的任务由电源所在电脑继续处理，请在该电脑查看结果或停止任务。远端设备重新连接后需重新刷新，旧命令不会重发。此功能使用现有未加密的局域网 WebSocket 服务，应在可信内网使用。

连接 Action 的 `scpiTrace` 及 State 的 `lastConnectDiagnostic` 保存连接过程中的逐条 TX/RX/ERROR 记录和失败 `stage`。响应保留可打印预览及最多 64 字节十六进制，Trace 最多 64 条；错误包含具体查询命令与超时收到的字节数。实机未验证；模拟器测试不能替代真实 IT6332A 固件、线缆或驱动测试。诊断记录可能包含设备身份，导出日志前注意相关信息。
