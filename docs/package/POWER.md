# IT6332A 电源管理

顶部“电源”打开控制页面，终端及其他连接继续运行。点击“连接”，选择 USB 或 RS232。USB 未安装 VISA 时，点击安装发布包驱动；完整解压后也可运行 `drivers/ni-visa18/setup.exe`。驱动安装可能要求系统组件及重启；由用户完成安装，不自动重启。Win7 需 SP1 及微软签名/系统更新。厂商原始驱动安装文件含 x86/x64 组件，应用只提供 x64。

RS232 的通信参数必须与电源面板一致，默认 9600/8/N/1。电源串口被独占，不能同时作为普通终端打开。不自动向全部 COM 发送指令。USB 选择 VISA 资源后通过 `*IDN?` 验证 IT6332A；接入时只读取状态，不复位或自动加电。

勾选 CH1/CH2/CH3 后，统一“加电”或“掉电”只操作所选通道。取消勾选不改变实际输出；状态来自设备回读。CH1/2 最大 30 V、6 A，CH3 最大 5 V、3 A。“应用参数”分别设置通道电压和电流限值。恒流限流通常为正常工作状态。

循环测试按当时选中的通道执行，加电和掉电时长单位为秒，最低 0.1 秒。通道操作顺序执行，不承诺同时切换。停止、任务完成和正常退出时尝试关闭任务持有的通道；失败显示未知并记录错误。手动掉电取消后续计划加电，未选通道保持当前输出，任务持有的通道仍在退出时处理。重连不恢复任务或重放加电。

采样间隔约 1 秒，通信耗时会延长实际间隔；三通道分别具有采样时间。操作日志与带表头的 CSV 测量文件位于 `%LOCALAPPDATA%\SerialCtl\logs`。单卷约 64 MiB，后续分卷带 `.partN`，CSV 表头在首卷；保存串口会话日志时合并全部分卷。磁盘写入失败或队列满时提示，不能继续宣称日志完整。通信异常停止任务并尝试任务通道掉电，最终状态标为未知。“保护”设置选中通道的电压/电流上限，电压保护写入设备 OVP 并回读；电流阈值与测量电压阈值由软件在采样时检查，触发后停止任务并掉电。软件检查有采样和通信延迟，不能代替设备限流、OVP/OTP 等硬件保护。已触发的设备保护需在面板排查并解除，不自动清除。

软件保护需在连接后设置；重新连接不沿用上次的软件阈值。开发基于 ITECH IT6300 Programming Guide V1.1（包含 IT6332A），使用 `INST:NSEL`、`CHAN:OUTP`、`VOLT`、`CURR`、`MEAS:VOLT?`、`MEAS:CURR?`；实际固件兼容性仍需实机核验。单通道开关采用手册第 30 页的 `CHAN:OUTP`，不使用整机 `OUTP`。

电源页面显示三个独立通道卡片，命令/SFTP 栏自动收起。顶部黑白圆形开关图标用于切换电源页面。远程 AI 可查询连接、测量状态及 selectedChannels，仅可调用当前勾选通道的总加电/掉电按钮；参数、保护、连接/断开及循环测试仅在本机操作。
