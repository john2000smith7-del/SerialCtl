# IT6332A 电源管理

顶部“电源”打开控制页面，终端及其他连接继续运行。点击“连接”，选择 USB、RS232 或模拟设备。USB 未安装 VISA 时，点击安装发布包驱动；完整解压后也可运行 `drivers/ni-visa18/setup.exe`。驱动安装可能要求系统组件及重启；由用户完成安装，不自动重启。Win7 需 SP1 及微软签名/系统更新。厂商原始驱动安装文件含 x86/x64 组件，应用只提供 x64。

RS232 的通信参数必须与电源面板一致，默认 9600/8/N/1。电源串口被独占，不能同时作为普通终端打开。不自动向全部 COM 发送指令。USB 选择 VISA 资源后通过 `*IDN?` 验证 IT6332A；接入时只读取状态，不复位或自动加电。

勾选 CH1/CH2/CH3 后，统一“加电”或“掉电”只操作所选通道。取消勾选不改变实际输出；状态来自设备回读。CH1/2 最大 30 V、6 A，CH3 最大 5 V、3 A。“设置”分别设置通道电压和电流限值。恒流限流通常为正常工作状态。

循环测试按当时选中的通道执行，加电和掉电时长单位为秒，最低 0.1 秒。通道操作顺序执行，不承诺同时切换。停止、任务完成和正常退出时尝试关闭任务持有的通道；失败显示未知并记录错误。手动掉电取消后续计划加电，未选通道保持当前输出，任务持有的通道仍在退出时处理。重连不恢复任务或重放加电。

采样约每秒一轮，三通道分别具有采样时间。日志位于 `%LOCALAPPDATA%\SerialCtl\logs`。磁盘写入失败或队列满时提示，不能继续宣称日志完整。通信异常停止任务并尝试任务通道掉电，最终状态标为未知。设备 OVP/OTP 等硬件保护需在面板正确设置；软件不能代替硬件保护。

模拟设备没有硬件输出，不应用于实际设备验收。开发基于 ITECH IT6300 Programming Guide V1.1（包含 IT6332A），使用 `INST:NSEL`、`CHAN:OUTP`、`VOLT`、`CURR`、`MEAS:VOLT?`、`MEAS:CURR?`；实际固件兼容性仍需实机核验。单通道开关采用手册第 30 页的 `CHAN:OUTP`，不使用整机 `OUTP`。
