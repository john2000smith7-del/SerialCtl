# SerialCtl V2.0.8

AI 页面增加鲸鱼娘宠物助手，沿用当前深浅主题、紧凑图标与双栏终端。

- 点开 AI 后约 4 秒，自动播放完整的三次跳步与拳击开场。离开 AI 取消；弹窗和最小化期间暂停，恢复后再等待 4 秒。
- 思考、工具执行、回复、完成和异常显示对应状态；开场结束恢复最新状态。宠物自身不会发送请求或操作设备。
- 点击挥手，连接栏内拖动；右键或 AI 顶栏小爪按钮可播放/停止、选大小、收起和设置。可关闭开场演示，偏好自动保存。
- 窗口较小时自动隐藏宠物停靠区，保留小爪按钮，不占用终端和消息输入框。

升级仍使用原 update.ini 地址与原签名身份。管理员将本版 ZIP 与对应 update.json 放入原静态目录，先 ZIP 后 JSON。
