# SerialCtl V1.0.4

Windows 7 SP1 x64 / Windows 10、11 x64，完整解压后运行根目录 serialctl.exe。

- 采用确认后的黑白顶部栏图标；电源使用普通圆形开关符号，桌面图标保留原样。透明图标资源支持 DPI 缩放。
- 默认浅色主题；电源三通道卡片横排，窄页面改为纵排；进入电源页自动收起命令/SFTP，切回终端恢复原有状态。连接与断开、加电与掉电独立控制。
- 恢复原先紧凑的单列添加/编辑命令窗口，不再切成两列。
- 电源连接只提供 USB、RS232；移除模拟设备入口。发布包继续包含 NI-VISA 18.0 Runtime 离线驱动。
- 删除顶部 API 入口和逐项授权窗口。固定网络接口随程序启动，串口/CMD 会话自动加入查询和收发；其他终端类型不开放。
- 电源网络接口仅保留状态查询与加电/掉电。输出操作采用本地当前勾选通道，远端不能修改通道选择、参数、保护、连接或任务。Linux 客户端无需 Token，on/off 命令不再带通道参数。

固定接口适用于操作者可控的局域网，防火墙按现场需要允许程序入站。Win7 实机、IT6332A USB/RS232、真实 SFTP 和长期压力测试仍需现场手动验收。自动测试不代替硬件验收；通信断开、软件崩溃或电脑掉电时无法保证电源已关闭输出。
