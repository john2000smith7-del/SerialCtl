# SerialCtl V1.0.6

- 收敛为一个 Win7 Winsock RFC 6455 WebSocket v1 服务，默认7000–7015。远程串口和两个 Python 入口共用协议，移除旧 TCP 串口与 HTTP REST 业务入口；权限保持原有 serial/CMD 和电源输出范围。
- 每客户端独立有界发送队列与事件唤醒，128连接容量上限，具名资源、多实例歧义、游标/缓存缺口与协议拒绝。GUI 直连内部服务及同一写 FIFO。
- CMD 本地 Unicode 行编辑、历史与保护草稿；网络完整行提交，真实隐藏 Win7 控制台代码页查询。管道 Ctrl+C/全屏交互明确不支持。
- 主屏幕逻辑行重排，保护活动行/历史/CJK/颜色与锚点；真实空行和日志时间戳一致。备用屏幕保留独立 VT 网格语义。
- 主动输入回到实时输出；侧栏/电源批量布局与标签失效；DPI加号、连接覆盖滚动和全部断开；串口错误诊断及可选 RX/TX Base64 核对。

硬件与 Win7 实测不能由 CI 代替：实际驱动、电源、Win7前后台/焦点、100/125/150/200%真实系统DPI、8小时现场稳定性仍需按交付验收记录执行。动态 runner 证据与自动回归只证明对应受控环境。
