# SerialCtl V1.0.8

- 终端完成拖选或双击选词后自动复制，右键直接粘贴一次；保留复制粘贴快捷键、中文、会话编码及 bracketed paste。
- 顶部新增“设置”，完整迁移原终端菜单功能，区分全局、当前会话及实例诊断的作用范围。
- 统一顶部导航、命令/SFTP、电源主分页、自动化与设备设置分类的圆角矩形选择样式。
- 主窗口和电源页共享圆角边框及下拉弹出列表样式，覆盖动态命令编辑行和相关弹窗；保持浅色、深色主题与 DPI 缩放规则。
- CMD 多行粘贴在发送前校验完整内容及尾行容量，避免部分提交后丢失草稿。

程序仍为 Win7 SP1 x64 原生应用，保持 /MT、PE 子系统 6.01、YY-Thunks、固定 PuTTY 和 NI-VISA 18 输入。正式包只从完整构建、测试和重新解压校验流程产生。

粘贴不会自动补回车，但剪贴板自带换行仍按会话规则处理；CMD 的完整行会执行。SFTP 文件操作菜单和普通输入框不采用终端的自动复制行为。

Windows Server 2022 构建及桌面测试不代表真实 Win7、物理串口、IT6332A、现场 SFTP 或八小时稳定性已经通过。具体结果以该源码提交对应的验收记录为准。
