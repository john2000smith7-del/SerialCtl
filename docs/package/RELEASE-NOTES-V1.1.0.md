# SerialCtl V1.1.0

- 仅发布 Windows x64 程序；ZIP 根目录直接包含 serialctl.exe、plink.exe、psftp.exe 和运行说明。
- 多个本地串口共用 TCP 服务，按 COM 名称隔离收发；7000 占用时自动尝试 7001–7015，共享端口全部不可用也不影响本地串口。
- 共享串口输入 IP 自动查询；提供 Python 标准库 Linux AI 客户端，支持 IP + COM5、查询参数与多串口同时连接。保持所有客户端可读写，不加入互斥。
- 取消底部发送窗口，终端右键增加粘贴和每会话换行设置；SSH Enter 保留标准行为。
- 命令拖动排序及编辑保持草稿，显式保存，退出时提示；本地保存使用临时文件替换，失败保留原文件。
- SFTP 增加 OSC 7 路径跟随、手动输入 pwd 路径、当前 Shell 获取路径/通知、跟随开关、可保存的名称列宽。
- 保留此前中文字体、标签高度、收起侧栏边界修复，深浅主题均进行 UI 验证。

GitHub Windows 构建及自动化测试、Win7 PE 导入/子系统检查、ZIP 重开和完整校验属于发布流程。尚未进行实际 Windows 7 SP1 与物理串口、现场 SSH/SFTP 测试；不能据此宣称已在真实 Win7 硬件验证。
