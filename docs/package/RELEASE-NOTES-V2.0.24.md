# SerialCtl V2.0.24

- 新增终端搜索栏（`Ctrl+F`）及搜索结果高亮与上下跳转导航。
- AI 会话支持多卡片并整合至左侧连接栏导航，支持卡片标题重命名及按卡片隔离的设备请求、执行输出与文件修改面板。
- TFTP 改为内嵌并后台托管原版 Tftpd32 4.74（`tftp32.exe`，EUPL v1.1），支持本地目录发布、单文件本地暂存发布及本机默认 IPv4 自动探测，同步更新 MCP TFTP 接口与更新器进程互斥检查。
- 精简电源面板布局并将参数配置整合至独立参数设置弹窗。
- 小猫桌面宠物切换为独立高清动作图集，优化动作表现；内置 Whisper tiny 语音模型采用 zlib 压缩打包并在运行时解压，保持单文件体积满足自动更新限制。
- 保持原签名身份、Windows 7 SP1 x64 目标与双文件自动更新兼容。

正式构建、签名和升级验证状态以对应 GitHub Actions 记录为准。
