# SerialCtl V2.0.3

Win7 SP1 x64 原生便携版本；交付完整 ZIP 和内嵌签名 update.json 两个文件。

## r2 自适应与重绘修订（产品版本仍为 V2.0.3）

- 小工作区或高缩放时，顶部导航切换为原有图标和名称提示，主题按钮独立且不遮挡设置。
- 电源操作区宽度不足时分行显示，模式下拉框、应用设置和上下电按钮互不覆盖。
- AI 连接、历史及设置弹窗高度适应工作区，底部操作固定，溢出内容可滚动并随键盘焦点显示。
- AI 窄对话区保留连接状态；窄终端使用紧凑换行资源图标，标题和按钮保持12像素间隔。
- 电源页面切换协调父子控件重绘，避免旧文字与新控件混合；剩余动作行统一12像素间距。
- 同版本修订仍需手动覆盖升级；在线更新继续仅识别更高产品版本。

## r1 界面修订（产品版本仍为 V2.0.3）

- 顶部 AI、电源及其他入口统一为按下深蓝、松开中性，移除鼠标焦点导致的常驻蓝色外框。
- 命令选中不再常驻深蓝；运行／编辑操作有独立按压反馈，左侧改为紧凑的 >_ 资源图标。
- 命令／SFTP、电源页面和自动化子选项使用中性当前态；电源选项增大内留白、统一12像素间隔并按需换行。
- 串口与远程连接下拉框恢复与输入框一致的高度，刷新按钮同步；本地硬件名称使用完整首行，UDP 通道名称和状态精简。
- 已安装 V2.0.3 的用户需手动解压覆盖本次 r1 包；在线更新仍只识别更高产品版本，不把同版本修订误报成新版本。

## 本次变化

- AI 与实时终端默认五五开，可拖动调整、双击恢复等分，独立保存比例和展开状态。
- AI 使用连续浅色／深色底面，两端留白细横线分隔顶部、消息与输入；不在顶部重复显示 jiojio 或角色副标题。
- 连接完成后 jiojio 首次介绍身份与能力；介绍不会自动读取设备或执行命令。
- 消息拖选文字后释放鼠标即复制，支持正文和代码，保留整条复制、键盘与历史滚动。
- 监视区隐藏程序附加时间戳；长行模式合并视觉软折行，保留设备硬换行，可切回自动折行。底部水平滚动不改变远端 PTY 或备用屏幕行为。
- 连接卡片使用顶部同一份图标资源，显示18逻辑像素；命令卡片无装饰图标，用单个小圆点标记拖动。紧凑工具图标18逻辑像素。
- 连接卡片可见高度48、命令卡片54；底板与工具图标采用内置资源，九宫格缩放保持圆角比例。命令只有居中小圆点，没有装饰图标。
- AI 输入区高96，目标收起时简洁显示，展开和悬停显示完整名称；移除底部模型占位。用户消息及选中态使用深蓝色。等待在消息区展示动态三点，成功过程自动折叠、可展开，失败过程保持可见，最终回答不折叠。
- 历史会话使用可搜索的统一主题弹窗，可请求服务器整理上下文。不支持时保留会话；服务器自动压缩能力以实际服务器配置为准。
- 原生服务器工具沿用现有 SSH 连接，停止及超过10分钟不再主动断开 SSH 或自动重发命令；模型自行发出的跨主机 SSH 仍属于服务器命令。
- 本地串口读取系统完整硬件名称，远程发现保留硬件描述与稳定 COM 标识，结果继续用下拉框。
- UDP 6333 是独立可选原始透传通道：只收指定来源 IP、按原始字节发送，不伪造未知协议的设备查询、身份验证或执行确认；等待数据状态与收到数据明确区分。原工具需正确配置目标 IP/端口和串口写回，不能用时可继续使用原 WebSocket 及其他功能。
- AI SSH 认证失败时清除当前账号保存的旧密码并提示重输，不自动删除或接受变化的 SSH 主机指纹。
- 同级矩形外距12；设置增加功能图标、实际版本和 Application design by jiojio。
- 可信新版先提示，点击确定后才下载，关闭提示退出；真实下载字节进度、校验阶段及失败重试，保留配置／日志／驱动和空闲安装保护。

## 更新部署

先上传 SerialCtl-V2.0.3-Win7-x64.zip，再替换 update.json，保持现有 update.ini 地址。V2.0.2 首次更新到本版仍按旧客户端已有流程；安装本版本后才显示新增确认交互。已启动设备任务时不突然重启，空闲时重新启动确认升级。
