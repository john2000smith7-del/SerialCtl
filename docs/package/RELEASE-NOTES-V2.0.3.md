# SerialCtl V2.0.3

Win7 SP1 x64 原生便携版本；交付完整 ZIP 和内嵌签名 update.json 两个文件。

## 本次变化

- AI 与实时终端默认五五开，可拖动调整、双击恢复等分，独立保存比例和展开状态。
- AI 使用连续浅色／深色底面，两端留白细横线分隔顶部、消息与输入；不在顶部重复显示 jiojio 或角色副标题。
- 连接完成后 jiojio 首次介绍身份与能力；介绍不会自动读取设备或执行命令。
- 消息拖选文字后释放鼠标即复制，支持正文和代码，保留整条复制、键盘与历史滚动。
- 监视区隐藏程序附加时间戳；长行模式合并视觉软折行，保留设备硬换行，可切回自动折行。底部水平滚动不改变远端 PTY 或备用屏幕行为。
- 连接卡片使用顶部同一份图标资源，显示20逻辑像素；命令卡片无装饰图标，用单个小圆点标记拖动。紧凑工具图标18逻辑像素。
- 同级矩形外距12；设置增加功能图标、实际版本和 Application design by jiojio。
- 可信新版先提示，点击确定后才下载，关闭提示退出；真实下载字节进度、校验阶段及失败重试，保留配置／日志／驱动和空闲安装保护。

## 更新部署

先上传 SerialCtl-V2.0.3-Win7-x64.zip，再替换 update.json，保持现有 update.ini 地址。V2.0.2 首次更新到本版仍按旧客户端已有流程；安装本版本后才显示新增确认交互。已启动设备任务时不突然重启，空闲时重新启动确认升级。

## 验证边界

以本版本测试记录和正式 Windows 构建结果为准。CI／交叉构建与离线进程、网络、设备替身不能替代实际 Windows7/10/11、现场 SSH 网关或真实串口、电源长时间验收。
