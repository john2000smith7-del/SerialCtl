# SerialCtl V2.0.11

- 优化 SSH、Telnet 和远程串口连接弹窗：只初始化当前连接类型需要的控件，减少隐藏控件的布局和重绘。
- 减少显示前的字体、边框和布局重复刷新；DWM 标题栏接口在进程内缓存，主机与端口默认值填写完成后统一更新一次主机身份状态。
- 保持深浅主题、控件高度、布局、SSH 主机身份核验及现有终端/AI/SFTP 功能。本版继续禁用电源连接和操作。
- 沿用原更新签名身份和 ZIP、update.json 两文件部署方式，保留配置、命令、日志和驱动。

Windows 自动测试与物理 Windows 7、现场串口及服务器验收分别记录；不承诺所有配置上绝对零延迟。
