# SerialCtl V2.0.9

- 桌面宠物可全局拖动，主窗口最小化后仍显示；右键可打开主窗口、返回窗口内、选择置顶及调整大小，位置自动保存。
- 软件限制同一 Windows 用户会话内一个正常主窗口，再次打开会唤回现有窗口。
- 修复命令卡片拖动闪烁、矩形背景跟随；拖动中的卡片显示深蓝色选中状态。
- AI 过程改为可读的中文操作记录，默认折叠；原始 JSON 放入技术详情，终端控制码不再直接显示在对话中。
- 修复等待动画偏移，以及“返回最新消息”与持续观察操作的位置冲突。
- 优化长对话、工具输出、展开过程和终端持续输出时的界面调度、长行测量及缓存，降低未响应风险。
- 连接弹窗先打开，再后台查询串口或电源设备。
- 新配置默认项目目录为 `/home/linux/workspace`；已有路径不覆盖。
- 更新仍只部署 ZIP 和配套 `update.json`，保留原签名及更新地址。V2.0.6 可直接跨版本升级。

兼容 Windows 7 SP1/10/11 x64 的原生程序。自动测试与实际 Win7、现场 Codex/Hermes、实体串口及电源验收分别记录；不把受控回放当作全部现场问题已复现或已通过。
