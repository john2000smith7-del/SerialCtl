# SerialCtl V2.0.2

- AI 目标选择支持已经连接的 CMD、Telnet、SSH、本地与远程串口；按连接类型显示来源，读取真实输出并发送单行命令，无需逐条确认。
- CMD 使用实际输入代码页及 CRLF 整行提交；保留有界日志、观察、目标固定、停止和不自动重发。
- 新增电源状态、输出 ON/OFF 和 action 结果工具。先在电源页连接 IT6332A 并勾选通道，再在 AI 对话中明确要求上下电；无需选择终端或二次弹窗。不新增电压、电流、模式设置或自动化工具。队列接受不代表成功，按逐通道回读判断。
- 升级后点击 AI“新建会话”加载新增电源工具；原历史仍可恢复，旧线程不保证能补注册新增工具。
- 保留 V2.0.1 顶栏、主题和间距修复，沿用原签名密钥。更新默认地址 http://172.16.3.188/external/serial/update.json，交付 ZIP 和内嵌签名 update.json 两文件；旧 INI 仍保留。先上传完整 ZIP，再替换 JSON，不解压或改名。
- 自动测试的受控传输与电源模拟回读不代替真实 Win7/10/11、SSH/Telnet、模型网关和实体电源/串口验收。
