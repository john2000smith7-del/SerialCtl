# SerialCtl V2.0.13

- 右侧命令卡片改为原生可编辑命令笔记，支持选择、复制、粘贴、撤销、无软换行及横向/纵向滚动。
- 只有一个运行按钮：无选区发送光标所在行；有选区按完整物理行顺序提交，跳过空行、注释及旧版宏标记。选择恰好结束在下一行开头时不包含该行。
- 当前行或多行选区的有效命令在行号旁显示运行图标；点击图标只运行对应行。正文双击运行默认开启，可从更多菜单关闭；Ctrl+Enter 与运行按钮相同。
- 保留保存、导入、导出及 UTF-8 文件拖入；导入只更新草稿，不自动运行。按钮采用共享 SVG 图标，窄侧栏自动保留图标与提示。
- 初次使用从原 commands.txt 带入内容，原文件保持；笔记独立保存为 command-notebook.txt。未保存关闭提供保存/放弃/取消；写入失败保留原文件。
- 批量发送使用不可变计划，固定目标会话、编码与换行，支持间隔设置与停止后续发送；切换会话、断线不重发，提交不等于设备执行完成。
- 主题按钮左侧在空间足够时显示多行运行提示，保持原有串口、SSH、AI、SFTP及原签名双文件升级机制。本版继续禁用电源操作。

验证范围以构建记录为准，不将受控 Windows 桌面测试当作物理 Windows 7 或现场设备验收。
