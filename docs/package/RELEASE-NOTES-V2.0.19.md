# SerialCtl V2.0.19

本版增加串口文件传输、命令持续发送和连接恢复，并统一原生界面细节。

- 普通 SSH 历史区分保存连接与记住密码，密码使用当前用户 Windows 凭据管理器，按主机、端口和用户名隔离回填。
- 修正命令注释绘制的末字裁剪，统一工作空间字段可见高度和胶囊自适应宽度。
- 统一日志分析与命令等弹出菜单，增加可检查后发送的分析提示词。
- AI 发送与停止合为一个图标入口，返回最新回答使用图标；优化历史会话列表层级。
- U-Boot 打断预设发送带前导空格的 ` stop`，间隔固定 500 ms；客户端识别实际命令提示符即停止，并使尚未写出的旧任务按键失效。支持跨接收包和 ANSI 颜色序列，向 AI 读取/画面结果同步已进入状态。UEFI F2 策略保持原有间隔选择。
- 新增 Xfer 右侧页签，提示“串口传输文件”；仅本地串口和远程串口连接后可用，其他连接类型禁用。已实现原始二进制、XMODEM、YMODEM、ZMODEM双向单文件传输；各模式最终验证状态以验收报告为准。
- 命令菜单新增默认关闭的“持续发送”，按设定间隔循环当前行或选中行，跨轮同样等待；红色暂停图标结束任务，支持立即重新运行。停止、切换会话或断开后不继续提交旧任务，已交给传输层/设备的内容不能撤回。
- 正文双击严格命中有效文本，空白区域不发送；修正本地回显行尾及软换行续行重复时间戳，不改变实际串口发送字节和接收VT语义。
- 断开释放真实连接并保留卡片，再点击同一位置关闭；绿色重连使用新连接实例并保留历史，支持取消重连，旧回调不影响新连接。底部“全部断开”完成后变为“全部关闭”。
- SSH启用Win7支持的TCP保活，修正断线收尾和重连路径；静默掉电检测时间仍取决于系统和网络。串口可恢复告警合并重复报告，保留真实flags与计数，不隐藏数据可能损坏的风险。
- SFTP与Xfer复用现有上传、下载、刷新和清理图标，保留工具提示与键盘操作；清理记录不删除文件。
- 延续既有开发发布流程和必要文件打包规则，保留离线驱动及接入工具。

保留 C++17／Win32、x64、/MT、PE 子系统 6.01、原更新签名身份和旧版升级兼容。宠物不在本轮修改范围。

验证结果以对应正式Release关联的源码与Windows、桌面、签名升级记录为准。受控进程、回环网络及独立协议实现对测不等于现场设备验收；真实Win7、现场SSH／模型网关、物理串口板卡和电源未运行，不宣称通过。长指令的板端回显与串口列宽/线路差异仍须结合现场原始字节核对。
