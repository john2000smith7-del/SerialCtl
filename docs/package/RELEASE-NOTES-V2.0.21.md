# SerialCtl V2.0.21

本版包含自 V2.0.19 以来的终端、文件传输、AI 工作空间和连接稳定性改进。

- 本地／远程共享串口物理 F2 默认发送精确 ASCII `232start`（无换行、不自动重复）；设置 → 快捷键设置可切回原生 F2，选择写入 `settings.ini`，自动 UEFI F2 打断保持原路径。
- 十六进制预览卡片新增 bit 31 至 bit 0 的点击翻转、动态计算和重绘；改动只在浮窗内，不自动修改设备寄存器或历史终端内容。
- 中文输入接受有效 UTF-16 代理对并拒绝无法被选定代码页无损编码的字符。宽字符被局部覆盖时避免留下半个字符，终端解析与合并绘制减少持续输出对界面的影响。
- 会话日志新增持续保存后台增量复制（从已持久写入的日志分卷读取）；断开后会保留源日志以供快照导出，使用原位重连时尝试在同一日志里续写历史。
- TFTP 可发布本地文件或经 SSH 流式读取的远端文件。MCP 可在 GUI 中启用，随 GUI 退出停止。局域网访问和电源操作受配置及授权约束。
- AI 支持本机语音转写、附件和工作空间事务。串口连接弹窗统一了本地与远程入口，侧栏快速切换在折叠动画中仍能接收鼠标点击。
- 自动更新继续使用原签名身份。下载请求遇到 HTTP 429 或 503 时，在原有总期限内最多重试两次。

正式发布的构建、桌面操作和签名升级验证以对应 GitHub Actions 记录为准。真实 Windows 7 SP1、物理串口与电源、现场 SSH 和模型网关的验证范围见当次交付说明。
