# SerialCtl V2.0.21 开发记录（未发布）

本文件记录正在开发中的变更，不代表已通过 CI、真实 Win7、物理串口或自动更新验收。

- 本地／远程共享串口物理 F2 默认发送精确 ASCII `232start`（无换行、不自动重复）；设置 → 快捷键设置可切回原生 F2，选择写入 `settings.ini`，自动 UEFI F2 打断保持原路径。
- 十六进制预览卡片新增 bit 31 至 bit 0 的点击翻转、动态计算和重绘；改动只在浮窗内，不自动修改设备寄存器或历史终端内容。
- 中文输入接受有效 UTF-16 代理对并拒绝无法被选定代码页无损编码的字符，宽字符被局部覆盖时避免留下半个字符；实际设备退格规则与历史输出保护仍需以现场 RX/TX 日志核对。
- 会话日志新增持续保存后台增量复制（从已持久写入的日志分卷读取）；断开后会保留源日志以供快照导出，使用原位重连时尝试在同一日志里续写历史。
- 源文件保护、日志轮转、失败提示与源快照导出逻辑仍应通过 Windows 全量测试及现场测试确认。旧版主程序、原签名身份、自动更新地址、发布资产均不修改。

验收状态：仅完成静态方案与部分可移植 C++17 单元探针；未运行 MSVC x64 Release、Windows CI、Win7 实机、现场串口设备或双文件签名升级验证。禁止用此开发记录宣称正式发布。
