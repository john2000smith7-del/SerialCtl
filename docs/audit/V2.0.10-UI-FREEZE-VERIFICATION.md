当前状态：**待 Windows 匹配提交的测试结果；不能宣称全部 UI 冻结验收完成。**

## 比较基线

接受程序来自 Actions 40631971674，源码 9d70d93abb068e808b9159c5fb8a7227aaf9c7bd。CI 下载精确 SerialCtl-Win7-portable Artifact，与当前候选 ZIP 在同一 Windows 桌面、同一窗口大小、字体和用户配置下顺序运行，保存两个 ZIP 的 SHA-256。

本轮不修改资源模板、颜色、图标、布局尺寸、字体、DPI 规则或控件风格。主窗口/终端改动仅涉及缓冲所有权和接收刷新调度；这项源码约束不能代替视觉结果。

## 自动比较

- tests/integration/ui_freeze_compare.py：浅/深主题 × 主窗口、SSH、本地串口、Telnet、远程串口、Settings，共 12 状态。
- 捕获实际可见桌面，比较客户区 RGB 像素和可见子控件相对矩形/启用状态；不比较系统标题栏和桌面时钟。
- 精确像素差或几何差均使测试失败；不以“看起来差不多”替代断言。
- 暂时停用宠物、隔离并恢复 CI 用户配置、关闭更新 URL，避免动画/用户数据污染比较。
- 输出：SerialCtl-UI-evidence 中 ui-freeze-comparison.json 及 freeze-baseline-*/freeze-candidate-* 截图。
- tests/unit/UiBufferedPaintTest.cpp 另比较持久位图与直接绘制 RGB，验证尺寸/DPI 键变化后的 GDI 释放。96/120/144 参数级绘制不是实际系统 DPI 测试。
