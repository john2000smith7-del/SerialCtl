# V2.0.10 UI 冻结验证

接受基线为 `9d70d93abb068e808b9159c5fb8a7227aaf9c7bd` 的 [Windows 构建 40631971674](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40631971674)。本报告的候选为 `23277a862cee1be79138847b35c8f422e53e8125` 的 [Windows 构建 40791932726](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40791932726)，包含异步设置保存及 `e7218ab` 的延后重排保护。

## 像素与控件几何

在同一 Windows Server 2022 桌面顺序运行两个完整解压包，窗口尺寸和配置一致，实际测得 96 DPI。客户区 RGB 逐像素比较，并比较可见控件的相对矩形及启用状态；系统标题栏和桌面时钟不在比较范围。测试隔离配置、关闭更新 URL、停用动态宠物，移走光标并消除文本插入光标。方法见 [ui_freeze_compare.py](../../tests/integration/ui_freeze_compare.py)。

| 主题 | 窗口 | 实际 96 DPI 结果 |
|---|---|---|
| 浅色、深色 | 主窗口、本地串口、远程串口、SSH、Telnet、Settings | 2×6 共 12 状态全部通过；变更像素均为 0，控件几何及启用状态相同 |

[原始截图及比较 JSON](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40791932726/artifacts/12863285682)包括 `freeze-baseline-*`、`freeze-candidate-*` 和 `ui-freeze-comparison.json`，保存两包 SHA-256、实际 DPI、各图片路径和比较值。候选 ZIP SHA-256 为 `a25b44e4d0e9a8f4f163641002433cd2bfe66e9194784421036399254f6e7001`。

`ui_buffered_paint` 另验证参数级 96/120/144 DPI 下的 RGB 等价和 GDI 生命周期；它不代表操作系统真的处于 120/144 DPI。

## 真实操作与回归处理

`23277a8` 的完整构建通过打包启动、GUI 与更新冒烟、实际命令鼠标拖动。41 项 CTest 及 [原生专项 40791936678](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40791936678)均通过，包括 5 次收显/交互重复和三个延后重排场景。

本源码的匹配手动桌面审计为 [40817386720](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40817386720)，输入构建为 `40791932726`；程序和测试脚本均为 `23277a8`。运行记录及其制品保存真实键鼠、持续 CMD 输出、窗口拖动/缩放、侧栏、SFTP fixture、截图/录像和程序校验值。该运行的最终状态以 Actions 记录为准；报告之后文档提交的匹配完整构建与手动审计由 [PR #32 验收记录](https://github.com/john2000smith7-del/SerialCtl/pull/32)绑定最终源码 SHA，不以其他提交代替。

开发中处理并保留以下回归记录：

- 持续接收续处理改为利用正常绘制机会，避免为推进接收反复重画整块主界面（`0345c79`）。实际可见绘制面和消息泵采样也补充了相应测试。
- 旧 `592c63d` 的[手动审计 40785811830](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40785811830)在浅色/深色持续输出下快速点击侧栏失败。[原始复核制品](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40785811830/artifacts/12860365958)及[提取结果](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40788057066)显示按下/释放均命中同一固定位置按钮，但 60ms 内标题未变化。这一记录不能单独证明磁盘是唯一原因。
- `1d58cdc` 将 UI 线程上的 25 项同步配置写入改为后台合并快照。[手动复测 40790764060](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40790764060)使用该包与生产源码一致的 `26c9378` 测试脚本，浅色/深色的实际键鼠和快速侧栏点击均通过；[原始数据](https://github.com/john2000smith7-del/SerialCtl/actions/runs/40790764060/artifacts/12862625521)保留。此结果不替代后续源码的匹配审计。
- 复查视口拆分发现遗漏了基线在拖动、动画期间延后终端重排的保护。`e7218ab` 恢复原规则；`ai_device` 新增实际改变终端尺寸时不重复重排、结束时提交网格的断言，`23277a8` 的专项和全量回归均通过。
