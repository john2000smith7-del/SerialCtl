# Windows 7 SP1 硬件验收

GitHub Actions 使用 Windows Server 2022 编译与测试，不能替代 Windows 7 SP1 验收。
V1.0.1 当前真实 Win7、串口硬件和长时间现场测试状态：未运行。

## 环境记录

记录操作系统位数与补丁、CPU、串口转换器型号/驱动、SSH/SFTP 服务器版本、程序版本和包 SHA-256。
32 位 Win7 使用 x86；64 位 Win7 分别验收 x64 与 x86。
完整解压，保留同架构 serialctl.exe、plink.exe、psftp.exe 在同一目录。

## 必测项目

1. 在无 .NET/VC 运行库额外安装要求的 Win7 SP1 机器启动程序，检查没有入口点或 DLL 缺失错误。
2. 深色、浅色、最小窗口与最大化；终端、连接对话框、首次主机指纹提示能正常绘制。
3. 实际串口回环收发 UTF-8、GBK/GB2312 中文、不同波特率和流控；测试拔插、断线和重新连接。
4. 接收持续串口流，连接多个共享客户端；其中一个停止读取，其他客户端和本地终端仍持续接收；记录是否丢字节。
5. Telnet 连接、SSH 登录、终端尺寸同步、vi/top 和断线；连接不可达地址时界面仍能操作。
6. 新 SSH 主机拒绝信任时不登录；独立核对后确认并重启，已保存指纹继续校验；更换密钥必须拒绝。
7. SFTP 中文路径、空格/通配符/符号链接、上传/下载/取消/重试；同名文件取消覆盖后原文件保持不变。
8. 同时操作多个会话与关闭程序，检查退出不挂起；连续运行至少 8 小时，记录内存、句柄和接收总量。

每项记录“通过 / 失败 / 未运行”，附实际证据。不得把静态 PE 检查标记为真实 Win7 验收通过。
