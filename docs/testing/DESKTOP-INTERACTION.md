# 真实桌面交互测试

最新 [2026-10-15 修复回归](results/V1.0.7-desktop-fixes-20261015/README.md)记录固定侧栏按钮、列表焦点的实际通过结果及新发现的深色展开白块；自动操作 PASS 不等于视觉完全通过。

已执行的 [2026-10-14 V1.0.7 实际审核报告](results/V1.0.7-desktop-interaction-20261014/README.md)记录两主题的真实鼠标/键盘结果、残留问题和原始证据；不能把脚本存在当作已经通过。

此测试在实际 Windows 桌面运行已构建的 SerialCtl，通过系统鼠标和键盘操作窗口。生产程序、界面和设备状态不由测试脚本重画。截图来自屏幕 DC 的 BitBlt / CopyFromScreen；原有 PrintWindow 图片仅作为单独的布局证据。

## 执行

推荐在 GitHub Actions 手动启动 `Desktop user interaction audit`，填写一个成功的 `Windows Win7 release build` run ID。工作流下载该次正式便携包，并检查其源码与本次测试提交的生产源码、VERSION、依赖和打包输入一致。测试脚本可更新，程序本体不必重新编译。

本地只在专用测试账户或临时虚机运行：脚本会重置该账户的 SerialCtl 布局，写测试命令，创建约 35 个真实 CMD 会话，并在隔离副本中替换 SSH/SFTP 子程序。请勿直接用日常工作账户执行。

```powershell
# 先把匹配当前 VERSION 的已验证便携 ZIP 放在 bin。
.\scripts\smoke-ui.ps1 -OutputDirectory "$env:TEMP\SerialCtl-desktop-audit" -ActualMouse
```

不加 `-ActualMouse` 时保留原有快速回归路径，其窗口消息和 MoveWindow 操作不等同真实点击/拖框。实际鼠标审核额外调用 `desktop_user_actions.py` 和 `gui_user_lifecycle.py`。

## 检查与证据

- 浅、深主题：实际点击连接入口、主题按钮、侧栏、命令编辑和电源分页，核对目标窗口和控件状态。高级共享端口通过“刷新”按钮的实际右键菜单进入。
- 实际拖动标题栏；右下角连续三轮缩小至约 980×620、扩大至 1180×760；双击标题栏最大化、恢复。记录输入轨迹及每次窗口边界。
- 原生拖动输入异步处理。鼠标释放后的固定 80 ms 采样不代表尺寸已提交；随后最多等待 500 ms 观察目标尺寸，并记录实际等待与边界变化。原目标尺寸容差、控件边界和响应断言不变，不重试拖动或调用程序性缩放；超时仍失败。
- 快速 Run/Stop 先观察原生界面已提交 1/2 的状态，随后立即发出 Stop；网络事件在两次点击后独立核对，不让订阅传输延迟消耗快速点击窗口。间隔按真实鼠标按下轨迹计算，必须小于系统双击时间；仍核对只提交第一条、第二条始终未提交及已接受工作继续执行。
- 右侧栏分隔线往返拖动、折叠展开、200 ms 动画内快速反向点击。检查内容可见性、控件边界和终端可用宽度。
- 侧栏按钮在普通折叠/展开与反向动画中保持原屏幕边界；分别执行十次交替点位点击和十次同点快速点击，每次释放均核对目标状态，再核对最终展开状态。同点输入记录系统双击时间及实际间隔，不以直接按钮通知替代。
- SFTP 名称/大小列边界双向调整；记录实际列宽和相邻列位置。此项使用隔离的 SSH/SFTP 子进程替身，界面仍为生产程序，不代表真实服务器已经通过。
- 持续真实 CMD / 受控 SSH 输出期间操作。用实际绘制的不同 stdout 标记证明输出与鼠标按住的时间重叠，不能只用窗口重绘计数证明。
- 桌宠按批准的出生锚点显示在状态区上方，置顶窗口可能覆盖列表。独立列表生命周期用例先用真实鼠标把仍启用、仍可见的桌宠拖到主窗口旁边，记录移动前、按住和释放后的屏幕帧及窗口边界；没有可用桌面空间、拖动失败或仍有遮挡就失败。此准备不关闭桌宠、不修改产品置顶语义，也不放宽后续 HWND/PID/WindowFromPoint 命中断言。
- 实际点击创建大量 CMD；系统滚轮、Home/End、覆盖滚动条拖动；“全部断开”后检查资源为空、原 CMD 进程树确实退出。列表初始锚点和通知刷新属于明确标记的测试准备操作。
- 列表连续 Home/End、方向键和翻页键保持列表焦点，跨电源项时核对中心视图；浅/深主题各执行一次不插入焦点恢复的序列。鼠标点击普通会话仍应进入终端。失败先保留原始观察，才恢复焦点继续清理。
- 浅、深主题的空闲真实 CMD：实际点击终端后，通过 `SendInput` 逐个输入 ASCII 字符及 Home/Left/Right/Delete/End/Backspace/Enter，检查焦点、HWND 和 PID。命令必须写出字节完全匹配的临时文件，并由只读 WebSocket 订阅读到独立输出行；再检查环境变量和工作目录跨命令保留。此项不使用直接发送的窗口键盘消息或 WebSocket 命令注入，中文 IME 不在覆盖范围。`*-cmd-real-input.json` 保存输入、原始事件和文件证据，同名前缀的 before/after PNG 来自真实桌面。

`actual-clicks.jsonl` 保存按钮输入；`*-user-actions.json` 保存窗口/控件几何、输入时间、逐项结论、截图 SHA-256、响应及输出观察；`gui-lifecycle.json` 保存键盘焦点、列表选择和进程清理结果。程序来源与摘要保存在 `interaction-receipt.json`、`program-package-sha256.json`、`program-executable-sha256.json`。

连续键盘操作失败后，为执行其余检查而进行的鼠标恢复会单独记录，不能抵消原失败。完整执行但存在行为失败时 lifecycle 返回 2；无法执行或断言异常返回 1；只有全部断言通过才返回 0。工作流失败也上传截图和日志。

侧栏快速反向输入若未改变目标状态，同样保留失败并返回 2；单独记录等待动画结束后的恢复操作，再继续深色主题及 SFTP 检查。记录鼠标按下/释放前的按钮边界和命中窗口，区分移动目标脱离指针与已送达的按钮通知，不能仅凭输入注入断言程序收到点击。外窗口拖动会临时开启系统“拖动时显示窗口内容”，并在退出时恢复原值。

## 边界

Windows Server 2022 和实际测得的 96 DPI 不代表 Win7、125/150/200% DPI 已通过。无实体串口、电源和真实 SFTP 服务时，只验证相应可运行界面及明确描述的替身层。

左侧连接框按窗口大小自动布局，没有独立拖拽入口；传输抽屉按展开/收起调整文件区，不能据此认定自由拖动缺失是实现故障。

截图是带实际时间戳的有限采样，不是固定帧率录像，不能证明采样间隔内绝无闪烁。最终结论应结合原图复审，区分产品问题、脚本问题、测试准备和未运行项。
