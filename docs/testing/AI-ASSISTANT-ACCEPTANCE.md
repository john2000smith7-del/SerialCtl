# AI V1 验证清单

自动测试由 CTest 纳入现有 `scripts/test.ps1`，只在支持的 Windows 构建环境中作为正式检查运行：

- `ai_protocol`：逐字节 UTF-8/JSONL 拆帧、上限、滚动锚点、命令边界和动态工具响应格式。
- `ai_client`：独立目录中的离线 `plink.exe` 进程替身，检查密码只经命名管道、首次指纹需要明确确认、协议握手、模型列表、流式消息、工具请求、停止，以及 UI 领域事件适配。测试假账号仅用于进程替身，不访问真实 SSH 网络，也不随发布包交付。
- `ai_pane`：真实 Win32 子窗口，使用合成消息检查不默认选本地串口、远程查询入口、滚轮/键盘/滑块、流式回复保留阅读位置、深浅主题及窄窗口输入栏边界。它不验证模型推理或物理设备。

现场验收必须逐项记录通过、失败或未运行：

1. Windows 7 SP1/10/11 x64、100/125/150/200% DPI；打开 AI、连接弹窗、输入框、长日志代码块，检查中文、键盘焦点、IME 回车、Tab、复制、主题和缩放。
2. 输入可达/不可达 SSH 地址、自定义端口、错误密码；取消连接；首次指纹拒绝、核对后信任、服务器密钥变化；密码不出现在进程命令行和诊断日志。
3. 默认不记住密码，重启后密码为空；明确勾选时由 Windows 安全凭据恢复。切换服务器/用户名、取消记住密码及凭据存储失败均不静默降级为明文。
4. 服务器缺少 Codex、App Server 无法启动、非 JSON stdout、超时、断网和服务退出；原串口、CMD、SSH/SFTP、电源继续工作，AI 显示错误且可恢复历史。
5. 只读显示服务器默认模型，无模型下拉/刷新/手工 ID；设置旧 Model 值后确认被忽略，创建/恢复会话均用当前服务器默认值；实际发送问题和调用工具验证网关兼容性，不能凭模型名称宣称已支持。
6. AI 中先不选择串口，不能将工具自动指向本地 COM。输入远程 IP，查询已开放串口，选择目标，核对对话里的 IP/COM 和实际命令目标完全一致。空列表、多个实例、自定义端口、断线、重启更换实例、查询中取消都应有明确结果。
7. 对照真实启动日志，读取最多 200/500 行，超过 64 KiB 时标明截断；原编码、来源、时间与游标真实。选中终端文本送入 AI 前不会自动上传；发送后分析只引用附加证据。
8. 连续长回复超过屏高，滚轮、拖动滑块、Home/End、PageUp/PageDown查看历史；阅读时再来新回复仍保持位置，点击“返回最新消息”才回到底部，输入栏始终在中心卡片内部。
9. 本地与远程串口分别直接提交诊断命令；确认不出现二次确认弹窗，未选目标、跨目标、重复调用和停止后均不能写入；核对实际收发字节和换行。发送队列接受只显示提交，设备无回显时不能标记执行成功；停止、断网和重连不自动重发。其他客户端同时输入不属于本版写入仲裁保证。
10. 新建会话、多轮对话、恢复历史、切换串口、切换 AI/电源/终端、全部断开与退出；没有旧任务改写新目标，UI 和串口接收不被模型等待阻塞。
11. 原有主要功能回归与长时间真实硬件测试。未运行的 Win7 或硬件项不得填写通过。

## V2.0.2 接入回归

- ai_device：实际 MainWindow 设备回调，受控传输覆盖五种连接的目标枚举、接收证据、编码/换行及断线；CMD 强制整行 CRLF。真实 PowerPane 勾选控件与 PowerService 模拟后端验证 ON/OFF、action 回读、未选通道不受影响、通道改变拒绝；不访问实体电源。
- ai_pane：新增电源无需终端选择、先读状态、直接提交、重复调用、越权 channels 参数、停止后拒绝和 action 查询。
- 现场逐项检查 CMD 中文/chcp、真实 Telnet/SSH 提示符及反馈；USB/RS232 电源 ON/OFF 的真实逐通道回读、断线/故障，停止后已提交动作不自动重发。升级前历史恢复后仍可查阅，新建会话可见三个新增电源工具。未运行项明确记录。

## V2.0.3 界面回归

默认展开并等分 AI／实时终端；检查拖动比例、恢复等分及原命令侧栏偏好隔离。连接节点复用顶部原图标，18逻辑像素。消息选择覆盖中文、代码、逆向跨段、实际鼠标释放复制、流式历史锚点；连续底色与两端留白分隔线。长行显示只合并软折行，保留硬换行、原始证据、远端宽度和备用屏幕；检查水平滚动与阅读位置。设置版本／英文署名、图标与12外距覆盖深浅主题和DPI。

本轮增加原始 UDP 回环测试（原样二进制、双向收发、独占端口冲突、取消和未连接发送拒绝）、嵌入资源存在与圆角底面检查、等待消息与成功／失败折叠差异、历史过程／最终回答边界及原生上下文整理事件测试。现场 UDP6333 需要与原串口工具实际报文和写回配置联调，不将受控回环当作该软件兼容性通过。密码认证失败与主机身份错误分别验证，清理密码不删除指纹。

## V2.0.5 回归

- ai_pane：流式执行阶段不折叠，正常完成后自动折叠；中间非零退出码保留摘要标记及原文，缺少 phase 的中间 AI 消息并入过程，最终回答独立显示。两主题检查原生点击重新展开，历史恢复采用同一规则，整个任务失败或停止不收起。兼容缺少 turn/completed 的 quiet completion。
- ai_protocol：历史回合 status 与 failedStep 分离，不把一条诊断命令失败误当整个回合失败。
- ai_device：真实远程连接弹窗仅一个串口下拉框，IP／刷新等高、紧凑页脚和布局不越界。受控 SerialCtl WebSocket 服务发现 COM3／COM5，停止服务后不出现 UDP 候选且连接禁用，不能提交无效目标。

V2.0.6 补充：未知、变化、主动重新核验均显示完整地址与指纹，复选框默认未选且直接 Enter／IDOK 无法跳过；取消不更改记录。先建立普通 SSH／AI 形成内存缓存，再轮换服务器密钥，核对后更新，同进程 SSH／AI／SFTP 使用新 pin。检查 PuTTY 历史缓存迁移、自定义端口隔离、第二次密钥变化、核验过程中取消、认证错误与网络错误、并发记录更新；不得自动重发设备命令或模型回合。深浅主题及小工作区检查两类连接弹窗、完整指纹、控件状态与滚动页脚。

## V2.0.7 补充验收

- 过程从开始/流式/停止/失败/历史恢复均默认折叠；用户展开后后续流式不抢回折叠状态，最终回答独立且显式 final_answer 可流式展示。
- SSH 普通 Enter 为 CR；增强模式按协商编码；text 不自动提交，key Enter 与人工共用编码，screen 为渲染屏幕；Shift+滚轮在 TUI 捕获时发 SGR 应用事件，无捕获时滚动本地历史，横向仍使用底部条。
- 目录下拉只展示真实可访问目录，有界500项；/home/linux不存在时实际HOME回退，nativeAPI缺失时argv原生命令回退；断线/超时不阻塞终端。不覆盖旧线程cwd，旧profile历史迁移及终端稳定身份唯一匹配。
- 电源布局浅深主题、默认50:50、拖动比例/折叠、正文裁切/滚动、固定页脚；真实USB/RS232连接弹窗。生产后端拒绝simulation，控制测试与实际硬件结论分开。
- 精确绑定板卡/通道，串口3–5秒静默只触发检查；OFF读回+至少10000ms才ON，取消/断线/身份模式变化不得续上电；U-Boot本地分包匹配、80ms有限3次、提示符证明进入、失败/停止不重发。
- 命令拖动浮层/占位、Esc/捕获丢失/越界取消、松手提交和边缘滚动；TXT拖入共享导入解析且绝不执行。添加命令按字体/DPI测量，不足显示图标并保留可访问名称。
- 用户服务器 Codex/Hermes 现场进入→滚动→尺寸拖动→中文→退出→Shell，以及真实设备/物理Win7，须另列现场记录。
