# V1.0.4 验收计划

自动验收在 GitHub Windows 2022 上运行，包含原有 14 套测试、包验证及实际 EXE 界面检查。完成结果以本次成功的 Actions 运行记录为准。电源测试使用测试程序内部控制的通信模型，正式应用无模拟连接入口。

| 项目 | 自动检查 | Win7 现场验收 |
|---|---|---|
| 图标与主题 | 默认浅色、深色切换、透明资源、六项导航、无 API 按钮、桌面图标不变 | 100%/125%/150%，无锯齿、缺图、裁切；电源为普通圆形开关 |
| 电源页面 | 980×620 与 1180×760 截图、三卡片横排、侧栏自动收起、切回 CMD 恢复 | 窗口缩放、滚动和 Tab 焦点，无重叠、闪烁；连接/断开不影响其他资源 |
| 连接弹窗 | USB/RS232 两种选择、无模拟入口、缺 VISA 提示、共用字体/字段/按钮样式 | IT6332A 实机接入、驱动安装、识别与型号回读 |
| 命令弹窗 | 一条、两条、十条单列截图，保存草稿、取消及前台状态 | 编辑确认不退后台；十条均可访问，不改动原有命令文件格式 |
| 固定接口 | 自动发现、无 Token；新 CMD 自动出现并收发；动态资源加入/移除 | 多串口独立操作，断开后不再收发；AI 与本地数据一致 |
| 电源远程范围 | 拒绝 connect/disconnect/parameters/protection/task/stop 和 channels 覆盖；仅 output | 本机 CH1/CH3 勾选后远端 on/off 仅影响 CH1/CH3；CH2 不变 |
| 稳定性 | HTTP 重连、WebSocket 二进制、环形事件限额；原有日志、队列、终端和串口回归 | 原有 SFTP、1 小时/8 小时压力、反复连接/主题切换，无崩溃或资源持续增长 |

真实 Win7、物理串口、电源、SFTP、DPI 现场及长期压力尚未运行，不得将 CI 结果表述为实机验收通过。
