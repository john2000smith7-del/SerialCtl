# 命令笔记验收

- 原生 CommandMacroTest 检查 UTF-16/CR/LF/CRLF 边界、正反选区、部分行完整提取、下一行首端点排除、注释/旧宏标记、UTF-8 原子保存。
- AiDeviceTest 使用实际 RichEdit 与生产发送入口，检查多行先提交/停止、拖入不执行、深浅主题截图、会话绑定及已有终端回归。
- gui_macro_submission.py 使用真实鼠标/剪贴板编辑笔记，通过真实 CMD 与网关事件验证提交早于执行完成、快速停止、断线和会话变动，不以函数返回成功替代设备回显。
- gui_command_notebook.py 与隔离 fixture 覆盖正文编辑、选区、双击、保存、导入/导出入口及宽窄布局，保留无损截图。
- 原卡片拖动测试由命令笔记测试替换；未变更页面仍比较实际像素与几何。只有明确批准的右侧命令内容区及顶部提示区域排除旧卡片基线比较。
- 正式发布保留全部 CTest、Win7 PE/导入检查、解压重验、原签名和旧客户端真实升级验证；未运行物理 Windows7/设备测试时明确限定结论。
