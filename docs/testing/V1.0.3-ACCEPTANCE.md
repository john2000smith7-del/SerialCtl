# V1.0.3 验收记录与测试计划

本版使用 GitHub Windows 2022 runner 编译和测试。Win7 SP1 x64、物理串口和 IT6332A 实机尚未验收。不得把模拟设备结果当作硬件验证。

| 范围 | 自动验证 | Win7 实机需执行 |
|---|---|---|
| 启动与退出 | 直接运行解压后的 x64 EXE；正常退出；PE 子系统 6.01、静态运行库及 DLL 导入检查 | 干净 Win7 SP1，普通账户、无 VISA 时启动；退出后无 CMD 子进程 |
| 连接与多串口 | 多串口独立流、端口占用后自动选端口、旧 V1/V2 客户端回归 | 同时 COM5/COM6，插拔、断开重连；仅选 COM5 时 COM6 不受影响 |
| 原有终端 | 编码分段、ANSI、滚屏、调整大小不生成空白历史 | 连续数据、空闲时拖动、Ctrl+C/Tab/Esc、右键粘贴、时间戳和日志逐项比较 |
| 命令 | 草稿、拖动、显式保存、未保存退出；多指令弹窗截图 | 点击编辑和确定后仍在前台；损坏文件、空文件、取消导入不丢数据；10 条宏全部可见 |
| SFTP | 模拟列表、路径输入、列宽拖动和收起侧栏，深浅主题截图 | 真 SSH 服务器传输/取消/失败；目录刷新时操作弹窗；拖动列宽无白块或全窗闪烁 |
| 图形界面 | 两种主题、最小窗口、所有原有连接弹窗及新增电源/API 弹窗截图 | 100%/125%/150%，1366×768；检查密码标签、重叠、边界、Tab 焦点、滚动、电源完整字段 |
| 电源连接 | 明确的模拟连接、型号确认、USB 缺驱动提示 | 发布包离线驱动安装；USB/RS232 型号与固件；独占 COM，禁止跟踪/串并联后独立控制 |
| 电源操作 | 通道选择、参数范围与回读、保护设置回读、批量非法参数无写入 | CH1/2 30 V/6 A、CH3 5 V/3 A；测量对照；单通道开关不改变其他通道 |
| 电源任务 | 循环完成/停止掉电、手动掉电取消后续加电且保留退出清理、超限停机 | 10/100/1000 次负载测试；USB 拔出、任务中关闭程序；无法确认时显示未知 |
| 本地 CMD | 同一进程环境变量跨命令保留、读写与进程树清理 | Win7 中文目录/命令；大输出；关闭连接；普通命令和脚本，不以全屏控制台程序验收 |
| AI API | 401/403、资源过滤、通道权限、授权更新撤销旧 token、HTTP 与 WebSocket 原始二进制、过期流明确 gap | 本地/远程操作同步可见；关闭 API 后不可控制；兼容 TCP 开关不关闭本地串口 |
| 日志 | 65 MiB 连续记录、64 MiB 分卷、全部分卷完整导出、保护原日志不被覆盖 | 磁盘满/无权限；CSV 采样时间和单位；出错后明确提示日志不完整 |
| 简单压力 | 接收/发送/日志有界队列；慢串口客户端回归；64 次 API 重连；1100 个事件淘汰 | 串口满速 1 小时、8 小时；CPU/内存/句柄稳定；反复开关连接和主题 100 次，无崩溃 |

硬件保护和软件采样保护分别验收。断线、进程被终止、电脑掉电时，软件无法保证设备关断；需要电源自身保护与测试台断电措施。软件计时不作为硬实时或三通道同步触发精度验收。

审核问题对应实现：模态确认不预先隐藏窗口；SFTP 拖宽仅布局表头；终端仅恢复由缩放形成的历史；命令损坏保护与空文件读取；导入草稿确认和受保护文件备份；控制键先于 TranslateMessage；模态 SFTP 操作快照；异步有界收发与日志、断线回读、密码不去空格、系统 DPI/字体/侧栏、宏两列、菜单选中状态、滚动条留白与长状态提示。
