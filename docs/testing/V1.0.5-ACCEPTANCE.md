# V1.0.5 验收

自动检查：14 组 CTest，电源服务增加组合参数、模式切换掉电、非法批量前置拒绝、预设范围、定时器回读、面板文本注入、独立硬件/软件保护、触发、序列完成掉电、定时任务停止后的防重启检查。Python 客户端协议测试及真实 GUI CMD 网络收发继续执行；拒绝所有新增远程电源写入接口。

UI：GitHub Windows runner 实际发布 EXE，深浅主题的独立/并联/串联/跟踪、四个分页、设备设置类别、全部自动化类别、步骤编辑弹窗、USB/RS232 连接、980×620 最小窗口。按 power-layout.json 对照 1044×760 布局：标题/连接按钮、模式/输出按钮、卡片、参数字段、主分页及内容边距。不得把浏览器原型或服务测试数据当作实机截图。

人工 Win7 验收（未运行）：

1. 100/125/150% DPI，窗口最小/最大/恢复，切页、切主题、重叠窗口及弹窗关闭；检查中文标签、圆角、背景擦除、焦点和前台位置。
2. 侧栏连续反转展开/收起 100 次；动画中持续串口/CMD 输出，确认最终尺寸、滚动位置和数据完整；直接拖动分隔条应即时响应。
3. 接 USB IT6332A，核对设备原有输出/参数未被连接改变；断电、拔线、读写超时及错误队列，检查未知状态和错误记录。
4. CH1/CH2/CH3 独立设定及极限值；只勾选一个通道操作，其他通道不变。按手册接线后测试 CH1＋CH2 串/并联，确认总值、两路实际值与掉电后的模式变更；跟踪为固定 1:1。
5. 循环、定时、序列：完成/停止/手动掉电/退出/异常保护时任务通道掉电，未来任务不重启。未选通道不受任务影响。断线后不宣称成功掉电。
6. 定时器整机作用范围；触发延时和步进设置；硬件 OVP 回读/触发/清除，软件检查延迟与磁盘日志失败。
7. 设备存储 1/36、预设恢复保持掉电、面板锁/本地/远程/显示文本、查询、状态寄存器、自检、复位和本机 SCPI；无新增 AI 控制权限。
8. 运行 8 小时采样/日志，同时 4 路串口与 CMD 数据和 SFTP 文件传输；监控内存、句柄、CPU、日志分卷、磁盘占满、客户端断开及退出时间。

编译/导入检查与 runner 截图不能替代以上硬件与 Win7 测试。
