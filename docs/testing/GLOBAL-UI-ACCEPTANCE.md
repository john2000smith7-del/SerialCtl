# V1.0.8 全局界面与终端鼠标验收

这是执行清单，不是通过证明。每次记录完整源码 SHA、程序 SHA-256、系统版本、实际 DPI、主题、包来源和起止时间。自动结果见对应 Actions 构建和桌面交互证据；不能用源代码或窗口存在代替行为结果。

## 自动执行

在 Windows 专用测试账户执行标准流程：

```powershell
.\scripts\check.ps1 -Architecture x64 -Configuration Release -SourceOnly
.\scripts\release.ps1
.\scripts\smoke-ui.ps1 -OutputDirectory "$env:TEMP\SerialCtl-global-ui" -ActualMouse
```

也可运行 `Windows Win7 release build`，成功后将该 run ID 传给 `Desktop user interaction audit`。桌面脚本应只消费源码匹配的已验证包。

新增 `gui_global_user_actions.py` 使用真实 Windows 鼠标/SendInput，读取真实剪贴板、CMD 输出和临时文件，并以桌面 BitBlt 保存截图。控件状态、owner、焦点及 DPI 查询是只读观察，不是输入替身。`PrintWindow` 图仅用于布局检查。

## 终端与设置

1. 对 SSH、本地串口、Telnet、远程串口、CMD 分别检查：拖动期间剪贴板不变，松开非空选区后精确复制；双击复制所选词；普通单击或拖滚动条不覆盖剪贴板。保存选区原图及剪贴板文本/UTF-8字节。
2. 覆盖中文宽字符、软折行、硬换行、历史及备用屏幕。软折行复制不增加换行，硬换行保留，时间戳不进入复制文本。完成选择后保留历史阅读位置。
3. 剪贴板放入一次追加文件的 CMD 命令，实际右键一次，文件必须只有一行；再粘贴不含换行的命令，按 Enter 前文件不能出现。记录命令、stdout原始字节、文件字节及截图。
4. 保留 Ctrl+Shift+C/V、Shift+Insert 和选区 Ctrl+C；键盘菜单键/Shift+F10进入设置，不能粘贴。无选区 Ctrl+C保持会话原有支持边界。
5. CMD多行分别覆盖 CR、LF、CRLF、行首/中间插入、8191/8192边界、超长尾行及无法编码字符。拒绝时不得部分发送，不清除原草稿；合法完整行执行，未换行尾行留草稿。
6. 无会话打开设置：全局回显/时间戳与实例诊断仍可用，会话设置及操作正确禁用。已有会话时确认编码、换行、原始字节记录、日志、清空、复制、粘贴、全选均能到达。
7. 设置修改后取消不提交，保存才提交。操作按钮按界面说明立即执行；保存日志/诊断的系统文件窗口以设置窗口为owner。另一个应用遮挡时关闭模态不能全局置顶或反复抢前台。
8. 切换两个会话核对各自编码/换行/原始字节设置隔离；设置中的全局选项影响整个窗口，实例诊断记录当前服务。

## 实际 DPI、连续操作及现场边界

每个系统在100%、125%、150%、200%真实显示缩放下重新启动应用，记录窗口GetDeviceCaps/实际字体和控件尺寸；禁止把图片缩放、仅改测试参数或注入固定DPI当作系统通过。

两主题分别执行最小约980×620（逻辑尺寸）、最大化/恢复、持续输出下连续缩放、侧栏拖动与快速反向动画、SFTP列宽拖动、电源分页切换。保留原尺寸截图、放大观察图及过程录屏；放大图仅定位边缘，不把位图像素格本身当成缺陷。检查圆角、边框粗细、中文截字、焦点、白块和残影。

真实Win7 SP1、物理串口、IT6332A、真实SSH/SFTP、中文IME及至少8小时现场运行，在没有相应环境时必须填写“未运行”。Windows Server 2022、模型测试和受控子进程只能证明对应已运行层。


## V2.0.3-r2 自适应回归

- 在实际100%、125%、150%、200%系统DPI及工作区约1600×1000时，导航不得与独立主题按钮重叠；紧凑导航保留所有入口、名称提示和键盘焦点。
- 电源模式框与三个操作按钮不得交叠；宽度不足时操作组换行，通道卡片与后续内容顺延，纵向滚动可到达最后一项。
- AI连接与设置溢出弹窗保持在工作区内；底部取消、提交及署名固定，滚轮、滑块拖动、Tab前后导航可完整查看内容，滚动内容不得覆盖底部按钮。
- AI分隔条向两侧拖到极限再恢复；实时终端标题、换行按钮、折叠按钮至少保留12像素间隔，连接状态不因对话区变窄而消失。桌面交互脚本新增实际鼠标AI分隔条拖动及原始截图。
- 电源设备设置四类快速切换，观察按下、释放及16/50/150/500毫秒画面；不得出现旧页文字与新页控件混合。UiRedrawScope必须保持隐藏页面隐藏。
- 检查自动化、设备设置与诊断动作组，所有同级按钮间距为12像素，主次、悬停、按压、禁用状态符合共享规则。
- `ui_dialog_viewport`覆盖系统先限制初始窗口的情况、固定底部、内容滚动与焦点自动露出；`ai_pane`覆盖228逻辑像素内部宽度。单元/进程测试不代替实际DPI桌面与连续画面审查。
