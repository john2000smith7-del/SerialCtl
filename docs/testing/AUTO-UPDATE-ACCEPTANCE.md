# V1.0.7 自动更新验收

本文件是验收步骤与证据要求，不是成功记录。测试实际结果必须关联源码完整 SHA、运行程序 SHA-256、服务器地址、清单/文件摘要、操作系统与运行日志。Windows Server 2022 CI、替身 HTTP 或受控文件操作不能替代真实 Win7 和内网服务器。未执行的项目填写“未运行”。

## 自动化要求

1. 清单解析：精确 schema/product/architecture/version、重复 JSON 键、未知字段/文件、路径穿越、大小/计数上限、重复文件名、非法 URL、缺必需文件都在执行前拒绝。
2. 信任：正确 RSA-SHA256 签名通过；改清单一字节、错误密钥、短/长签名、未签名输入拒绝。文件内容、长度、SHA256、VERSION 不匹配拒绝。
3. 网络：完整下载、半途断开、404、超限响应、慢响应、超时、取消、跨源重定向与返回登录 HTML；旧版继续可用，失败不能执行 staging。
4. 安装：正常替换/重启，目标占用、目录只读、部分替换失败回滚，多实例拒绝安装，退出和取消不丢用户文件。构造故障时必须核对原文件摘要，不以“返回失败”代替回滚证明。
5. 签名发布工具：正确包产生可验签静态目录；错密钥、损坏包、缺必需文件、已有输出目录拒绝；确认 `update.ini`、驱动、密钥、源码、本机配置未被复制。

## 实际窗口与现场步骤

| 场景 | 可执行步骤 | 预期与证据 |
|---|---|---|
| 无配置 | 清空/移走 exe 旁 INI 后启动 | 正常打开，无猜测的服务器请求；抓包及进程日志 |
| 修改网址 | 将 INI 指向受控静态服务器 A，重启；改为 B 再重启 | 请求分别到 A/B，自动更新前后 INI 摘要不变 |
| 无更新/离线 | 发布同版/低版清单；停服务器，再启动 | 不降级，不阻塞启动；截取可用主窗口与网络错误 |
| 正常更新 | 空闲启动旧版测试副本，发布用同一信任链签名的更高版本 | 退出、替换、重启；核对窗口版本、每个文件 SHA256、日志和旧版备份 |
| 工作期间延后 | 让下载暂停，打开真实 CMD 并运行持续输出后恢复下载；另测串口/SFTP/电源任务 | 会话运行不中断，不因更新退出；本次运行不再自动重启，结束工作并在空闲时重启后才重新检查安装；记录进程树和连续桌面录屏 |
| 多实例 | 从同目录开两个实例，另目录开一个；对首目录推更新 | 同目录实例仍运行时拒绝本次安装且不覆盖文件；关闭后重新启动再试；另目录不被影响；进程与文件摘要 |
| 模态与命令草稿 | 打开命令编辑并修改未保存草稿，随后完成更新下载 | 不能在模态或未保存工作时丢草稿；保存/取消按既有策略；录屏 |
| 数据保留 | 创建命令、日志、INI、用户文件；给 drivers 文件记录摘要，再升级 | 所有用户文件和 driver 摘要不变，仅批准文件替换 |
| 篡改/错误包 | 清单改字节；文件改字节；错签名；路径注入；网络返回 HTML | 拒绝安装，旧 exe 和用户文件哈希不变，错误原因可追溯 |
| 下载取消与断网 | 大文件慢速服务器，下载中正常关闭应用/断网络 | 有界退出，无残留工作进程；旧程序再次可正常启动 |
| 文件占用/权限 | 外部进程拒绝写锁住一项已存在目标；目标目录只读 | 不提权、不宣称成功；失败回滚后全部旧文件哈希一致 |
| 磁盘失败 | 在隔离虚拟磁盘限额下让下载/备份/替换逐阶段空间不足 | 记录每阶段行为，旧版是否可用、备份恢复是否成功；不能只测下载失败 |
| 安装中止 | 在隔离测试副本分别于备份后、替换中、重启前杀更新进程/强制关机 | 记录实际恢复路径与残留；若需人工解压恢复必须明确，不能宣称已自动回滚 |
| 真实 Win7 | Win7 SP1 x64，无 .NET/VC Runtime 附加安装，完整两版本升级 | 无缺失 DLL/API，HTTP 正常；HTTPS 独立验证系统补丁/证书；保存系统信息与桌面证据 |
| 真实服务器 | 在 172.16.2.188 最终目录部署，用生产客户端请求 | 状态码/MIME/权限/缓存/签名正确；在发布窗口切换清单，签名不一致只延后更新 |

真实服务器路径/登录条件尚未确定；真实 Win7、硬件联动、磁盘掉电和长时间现场结果目前不得标为通过。保留启动前后截图、连续桌面录屏（不是 PrintWindow 重绘证明）、原始 HTTP 日志、更新日志、签名与清单原始字节、所有前后 SHA-256、进程/线程/句柄、取消耗时和复核人。
