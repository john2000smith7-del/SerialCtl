# 尚未运行的现场验收

使用专用测试账户和可恢复的设备配置。先记录系统版本、DPI、显卡/远程桌面、EXE SHA-256、源码版本和串口速率。每项保存开始/结束时间、输入步骤、原始日志及真实桌面录屏；不要仅用 PrintWindow。

| 待测场景 | 操作与预期 | 采集 |
|---|---|---|
| Win7 SP1 x64 | 全新机器不装 .NET/VC runtime，运行正式包；连接、CMD、退出无缺失导入；保留 YY-Thunks/PE 检查并另测真实系统 | OS、依赖列表、启动/退出日志、事件查看器 |
| 125/150/200% DPI | 系统设置真实 DPI，注销/登录；记录实际 DPI，重复最小/最大/恢复，中文/加号、10 步编辑及重启侧栏宽度 | 每个 DPI 的原图、对话框与工作区边界、窗口几何 JSON |
| 持续实体串口输出 | 对端产生带序号及 CRC 的 0–255 全字节流；同时收发、缩放、拖侧栏；不同 COM 使用不同流 | 两端二进制原流、字节计数/CRC、显示录屏、速率/线缆/驱动 |
| 真实 SFTP | 两主题大目录/长中文文件名，列宽、抽屉、传输中收起展开；上传下载校验，断网/取消/全部断开 | 服务器与客户端日志、文件 SHA-256、任务最终状态、进程树 |
| IT6332A | 编辑参数时监测刷新、快速分页、勾选通道总输出、运行任务后停止/退出；只关闭本次任务控制通道 | SCPI/驱动日志、仪器面板视频、独立实测通道输出 |
| 电源断连 | 发 OFF 时拔线/断电，界面必须显示无法确认而非成功掉电；重连后可核对真实状态 | 发出/响应/失联时间、告警与最终任务结果 |
| 其他程序遮挡 | 打开编辑框，用真实鼠标切到记事本；保存/取消/Alt-Tab；owner 正确且不全局置顶、不持续抢前台 | 全屏录屏、foreground/owner 变化 |
| 真实 IME/剪贴板 | 中文输入法组合、左右光标、中文删除、带 CRLF 多行粘贴；异步输出中保持草稿，Enter 执行真实结果 | 按键/IME 操作录屏、实际文件/原始输出、草稿和历史 |
| 主窗口真实退出 | 点标题 X/Alt-F4，分别在无任务、CMD运行、SFTP传输、电源任务时退出；取消退出可恢复工作 | 子进程/句柄前后快照、设备释放验证、退出码 |
| 1/2/8/32 网络客户端 | 从受控局域网逐级接入，隔离不同 COM，加入不读取的慢客户端、频繁重连和大输入 | 队列水位/拒绝/溢出、原始字节校验、CPU/内存/线程/句柄时序 |
| 延迟与8小时稳定性 | 区分发送→设备、设备读取→网络、PostData→实际绘制；明确负载、客户端/资源数、网络拓扑；至少8小时 | 原始样本、P50/P95/P99、累计资源变化与所有错误，不用短时结果替代 |
| 磁盘/网络失败 | 受控填满日志卷/撤销写权限、断网、拔设备后重连；明确日志失败、不自动重放已执行输入 | 文件系统错误、网络抓包、唯一执行标记、恢复状态 |
| 内网更新服务器 | 最终配置 update.ini 的 URL；使用生产签名更新包测试成功、失败、取消/恢复及旧程序保留 | HTTP日志、签名前后SHA-256、INI内容（隐藏秘密）、安装器结果 |

执行者为每项填写通过/失败/未运行、具体日期和证据路径；硬件/网络缺失时继续保持“未运行”。高 DPI、Win7 或设备现场未完成前，不应将本次 Server 2022 结果写成上述平台/设备已经通过。
