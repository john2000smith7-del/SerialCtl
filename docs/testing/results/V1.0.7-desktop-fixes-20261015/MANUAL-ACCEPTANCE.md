# 修复后的现场补验

本页列出的项目均未由本轮 Windows Server 2022 / 96 DPI 短时回归证明。通用硬件、内网、压力和 8 小时步骤沿用[完整人工验收表](https://github.com/john2000smith7-del/SerialCtl/blob/main/docs/testing/results/V1.0.7-desktop-interaction-20261014/MANUAL-ACCEPTANCE.md)。不要用本页勾选框代替原始证据。

在专用测试账户使用与报告 SHA-256 一致的程序，记录 OS、DPI、显示器、程序摘要及输入设备；每种主题单独保存录像、操作记录和日志。

| 项目 | 操作与预期 | 证据 |
|---|---|---|
| Win7 SP1 与高 DPI | 在 Win7、Win10/11 的 100/125/150/200% 实际 DPI 下，连续缩放到约 980×620、最大化/恢复；拖侧栏并展开/收起。按钮完整、间距一致，正常动画时按钮固定；窗口本身移动/缩放时屏幕坐标变化正常。 | 系统显示设置、程序哈希、全屏原始录像及起止截图；记录采样率和丢帧。 |
| 侧栏 100 次快速反向 | 浅/深主题、命令/SFTP 两页、持续输出，普通与同点快速点击分别至少 100 次；每次释放改变目标状态，旧位置不残留箭头/蓝边。 | 连续录屏与鼠标时间，不能只截最终帧或使用 PrintWindow。原问题 #15 的完整视觉验收在此补齐。 |

| 首次动画 tick 前反向 | 受控 Win32 输入在首次约 16 ms 动画 tick 前连续反向，并重复 8/30/100 ms 按压；最终目标/布局一致，无残留 timer 推动过期状态。 | 诊断版本消息时间与生产版视频分开保存；不要仅按注入时间推断消息到达时间。 |
| 导航不产生设备输入 | 真实 COM 连接至字节采集端；列表获焦后连续 Home/End/上下/翻页，经过电源项，再点击普通会话。键盘阶段焦点留列表、中心视图匹配；鼠标选择后终端获焦；导航阶段设备未收到输入。 | 同步保存 HWND/焦点、接收端完整字节及时间；CMD 草稿在切换后保持。 |
