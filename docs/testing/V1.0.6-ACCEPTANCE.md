## 测试边界与协议保证

受控 Echo transport 代替物理 UART，但网络服务、RFC6455、内部会话、发送 FIFO 和桌面远程串口均为生产 C++。Python 在 Linux 验证核心，并在 Windows runner 与生产 C++ 服务互通；这不等于真实 Linux 到 Win7 有线 LAN。真实 cmd.exe 与打包 GUI 冒烟使用系统接口；测试 SSH/SFTP UI 的 mock 明确隔离，不进入 ZIP。电源测试使用受控后端，用户无 IT6332A，实体电源未验证。

每连接最多128总连接、每客户端4MiB/4096消息队列、输入8MiB FIFO、每资源历史1MiB/1024事件与总16MiB历史。大小/权限/类型在执行前验证；输入接收/排队与执行完成分别表达；无写租约或任务级互斥；断线输入不自动重发。详见 WEBSOCKET-PROTOCOL.md。

## 测量与尚未运行

转发计时是 ApiServer::Publish 入口到客户端完整解帧/校验，回环网络、两路受控 COM、64字节×1000包，依次读取各客户端样本包含接收顺序开销。P50/P95/P99 原始结果在 CTest artifact；以最终运行数据报告，不把超时值当延迟。

显示计时是 GUI PostData 到实际终端 BitBlt 完成，100样本/主题，opt-in SERIALCTL_UI_METRICS 不写热路径磁盘；不是显示器物理呈现/DWM延迟。GUI 动态记录包括 CopyFromScreen 真实桌面中间帧和 PrintWindow 布局图，后者不证明重绘无残影。

未运行：真实 Win7 SP1、125/150/200% DPI、真实 UART/拔插/线路错误、有线 LAN、IT6332A USB/RS232、真实 SSH/SFTP 服务器及至少8小时现场运行。自动短压力检查不能替代这些项目。人工步骤见 WIN7-HARDWARE-TEST.md 与 MANUAL-REGRESSION.md。

补充模型复现：初始硬换行共用ID造成锚点错行，行尾SGR清掉wrap-pending会覆盖最后一字符，空白区DCH后回车再缩放会错误丢前面的字符。新增断言先失败后修复通过；Windows最终回归仍需核对。连接列表改用内部会话ID作为顶部锚点，避免多条同名CMD重新建列表时跳到第一项。
